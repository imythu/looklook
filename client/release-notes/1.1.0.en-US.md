Looklook client 1.1.0: terminal tasks now keep running after you close the page, plus a remote-connection fix.

- New: Looklook now ships with its own terminal session manager (looklook-mux), so you no longer need to install tmux yourself. Tasks started in a terminal keep running when you close the page or the browser, and you can reopen them later.
- Fixed: after stopping and starting Looklook from the tray menu, remote access could fail with connection errors. Stopping now fully shuts down the background connection.
- The terminals-first layout is kept; the safety notice and the missing-tmux warning are now folded away so they take less room. The "open on phone or another computer" card is now a single collapsed row.
- Note: the bundled session manager on Windows, macOS and arm64 devices has had limited testing. If you run into problems, please let us know.
