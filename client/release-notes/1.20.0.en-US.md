Looklook desktop 1.20.0: a redesigned sessions page that makes new sessions quicker and keeps many computers and projects easy to tell apart.

- Sessions are grouped by project in the left sidebar; click + next to a project to start a new session right away (with undo)
- "New session" opens a start page: pick the computer, project and tool, describe the task, and press Enter to begin
- The tab bar at the top is gone; switch sessions from the sidebar. The 8 most recent sessions stay connected, so switching back is instant
- The sidebar folds into a row of icons, and the tools menu and each project can be collapsed
- Each computer gets its own color and an OS icon, and AI coding tools show their official icons
- Routes are shown by name only, without the location
- Fixed a crash on macOS when opening DSH or a terminal in a new window
