Looklook desktop 1.36.2 fixes the limits on the usage page.

- Fixed: the Claude Code 5-hour and 7-day limits were still missing from the usage page when Claude Code could not save its config file (for example in Docker, when `~/.claude.json` is mounted as a folder). Looklook now uses the numbers Claude Code reports when it checks usage (this uses no quota); Looklook still never reads your sign-in credentials.
