Looklook desktop 1.58.0: when you forward someone's issue to the AI in Feishu, it now goes to the right project based on who reported it, with one session per issue.

- New: Issues you forward to the bot (merged forwards, or messages starting like "Alice: …") no longer go into the current session; each gets its own new session. The project is picked in this order: a #project you wrote → a session from the same person within a day (continued, with a "New issue" button) → "Always send this person's to this project" if you set it → the project this person's last few issues went to. Otherwise you get a picker card, with a project preselected if its folder name is mentioned. Use "merge forward" (even for one message) so the sender is known.
- New: Write @codex or @claude in a message to pick the assistant; send "done" when something is finished, and your next message starts a new session.
- New: Answer cards now have "Reply to them" (the AI writes the reply and, with the Feishu CLI installed, sends it as you after asking), "Other project" and "Move to a session". The project picker also offers "Misc" for things like drafting or translating that don't belong to a project.
- New: The first time you @ the bot in a group, it asks which project the group is for and can remember it.
- Changed: For AI assistants to use Feishu as you (read group and direct chats, look people up, read and write docs, send messages), Looklook now points you to Feishu's official command-line tool lark-cli: install it with one click on the "AI assistants" page, and Claude Code and Codex use it right away. The Looklook Feishu app no longer needs user permissions. The old Feishu MCP tools are removed.
- Improved: The instructions AI assistants get when they connect to Looklook are written around real situations, so they use local pages and SSH tools when it makes sense.
- Fixed: Tab groups no longer shift when switching between chat, terminal, Git and files; starting a new session from an earlier Codex chat no longer shows an empty terminal.
- Fixed: On Mac, the cursor didn't go to the input box after switching sessions.
- Fixed: Images you sent in a chat kept spinning; the add-project search box had a double border.
- Fixed: A black frame around the terminal, and the bottom two lines cut off the first time it opened.
