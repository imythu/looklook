Looklook client 1.16.1: fixes the macOS desktop app crashing when opening DSH or a terminal in a new window, adds installing into Docker containers, makes terminals draw and stop more reliably, and withdraws the 1.16.0 conversation moving, history and chat view.

- Fixed the macOS desktop app crashing when it opened DSH at startup or when you clicked "Open in new window" at the top right of a terminal.
- Install Looklook into a running Docker container: run the command from the Download page on the Docker host. The container doesn't need curl. Run it with sudo to add a service on the host so Looklook starts again after the host or the container restarts.
- Opening a session page now focuses the terminal in front, so you can type right away.
- When you come back to the window, terminals refit and redraw completely instead of staying partly drawn (for example with the AI's input box missing).
- Stopping a terminal now ends every program it started. Deleting a running terminal stops it first instead of refusing.
- New "Select text" view (top bar button, or long-press on phones) shows the last ~3000 lines as plain text for easy selecting and copying. A Copy button appears when the browser blocks the terminal's copy.
- Fast swipes in a terminal on phones scroll smoothly instead of stalling.
- New terminals are named after their folder, for example "my-app · Claude Code".
- Withdrew the 1.16.0 conversation moving, conversation history page and chat view. The composer, the "DSH (terminal)" session type, page sharing and other features are unchanged.
- On Linux without systemd, running the install command again now upgrades cleanly.
