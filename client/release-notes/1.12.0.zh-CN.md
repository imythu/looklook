看看电脑端 1.12.0：文件管理、Git、SSH 主机，终端更好用。

- 新增“文件”页：浏览这台电脑上的文件，预览文本、图片和 Markdown（排版显示），上传、下载、新建文件夹、重命名、删除；把文件拖进列表即可上传。
- 终端页顶部改为“终端 / 文件 / Git”三个标签。Git 标签显示当前分支、改动和提交历史，点文件或提交查看对比，可以暂存、提交、抓取、拉取（只快进）和推送。
- 新增“SSH 主机”：保存常用的服务器，一键打开 SSH 终端，不用每次输密码。密码只在这台电脑上加密保存，连接时由看看交给 ssh，不会显示，也不会出现在终端里。标了“允许 AI 助手使用”的主机，Claude Code、Codex 可以经 MCP 在上面运行命令，但看不到密码和私钥。
- 在终端里粘贴截图后，右下角会显示缩略图，点开看大图或删除；“设置 → 粘贴的图片与附件”可以查看、删除、清空，并设置保留天数（默认 7 天）。
- 会话页底部新增终端切换条：点一下打开或切到最前，再点一下最小化；也可以按 Alt+1…9。
- 选中终端里的文字后旁边会出现“复制”按钮；Windows / Linux 上也可以按 Ctrl+Shift+C。
- 修复：用中文输入法时打不出全角括号（），以及部分中文标点变成英文标点。
- 远程连接更稳：电脑睡醒或换了网络后立即重连，不用再等半分钟；右上角显示远程连接状态，可以一键“立即重连”。
- 修复：Mac 版看看只在菜单栏运行时，从远程地址打开可能显示电脑离线。
- 终端默认配色换成更柔和的“AI 助手风格”暖色深色，原来的深色、浅色仍可在设置里选择。
