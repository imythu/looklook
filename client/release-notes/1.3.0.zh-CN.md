看看客户端 1.3.0：Windows 和 macOS 改成桌面应用，Codex 对话支持全部权限。

- 新：Windows 和 macOS 提供安装程序（Windows 的 setup.exe、macOS 的 .dmg），像普通软件一样安装。打开后在看看自己的窗口里显示管理台，不再打开浏览器；关掉窗口后继续在后台运行，点托盘（菜单栏）图标重新打开。
- Windows 版目前是 Beta 测试版：可以使用，但还没有经过充分测试，遇到问题请在“设置 → 问题与日志”里反馈。
- 新：Codex 对话可以勾选“以全部权限打开”，不再逐条确认、不启用沙箱。
- 改进：新建终端后会询问怎么打开：在当前页面的小窗口里打开，或者在新标签页打开，不再直接跳走。
- 修复：从桌面图标或托盘启动看看时，明明装了 Codex 却提示“无法启动 Codex：No such file or directory”。
- 修复：macOS 上程序坞里多出一个“exec”图标。
- 改进：远程连接断开后能更快发现并自动重连。
