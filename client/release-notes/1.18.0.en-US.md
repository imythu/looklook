Looklook desktop 1.18.0: Codex sessions now have the chat view too, the same one Claude Code uses — send messages, follow replies and commands, and approve actions in the chat, also on a phone. Looklook also finds the Claude Code that comes with Claude Desktop.

- Codex sessions get a "Chat" tab (on by default for new sessions): replies, commands and their output, file changes (diffs) and to-do lists are shown as cards, just like the Claude Code chat view. Existing Codex sessions have it turned on after the update; it takes effect the next time the session starts.
- When Codex wants to run a command or change files, tap "Allow / Deny" in the chat (and tell Codex why when denying), or answer in the terminal; stop a run at any time.
- The first time Codex starts in a folder, confirm "Trust this folder?" right in the chat instead of switching to the terminal.
- A Codex that was already running before the chat view was turned on shows "not connected to the chat view", with a one-click restart to connect it.
- Codex in chat mode gets its hooks from Looklook's own profile (`~/.codex/looklook-chat.config.toml`); your own Codex config is not changed.
- Not yet in the Codex chat: sending images, "allow for this session" and plan approval — use the terminal for these. Codex versions not yet verified show a notice at the top of the chat.
- If `claude` is not on your PATH but Claude Desktop is installed, new Claude Code sessions use the Claude Code that comes with Claude Desktop.
