看看电脑端 1.30.0：Codex 对话改由看看直接驱动，可以选模型、看账号用量，生成的图片直接显示在对话里；Claude 的用量和桌面版一致了。

- Codex 对话改走 Codex 的 app-server：回复边写边显示，审批、提问在对话里回答，运行中可以插话或停止；“终端”标签是同一个文件夹下的普通终端。以前在终端里开着的 Codex 会话，打开对话时会自动接上原来的对话。
- Codex 可以在对话里选模型和思考强度，用量栏显示账号、套餐、5 小时和每周额度、上下文占用。
- Codex 生成的图片直接显示在对话里（手机上也能看到），每张图有自己的地址，可以查看原图、下载；新的“资源”栏列出这段对话生成的图片和用到的网页、搜索。
- Codex 产出的文件（新建、改过的文件，PDF、表格、视频等）在“资源”栏里列出来，可以打开、下载；回复里提到的这些文件路径也能直接点开。
- Claude Code 的用量改为实时取，和 Claude 桌面版、/usage 看到的一样，不再显示几天前的旧数字。
- Claude Code 弹出选择框时，在对话界面里选择、关掉都更可靠；停下来以后点“停止”不会再误开回退菜单。
- Windows 上 Codex 的输入框里不再出现 `[<35;45;31M` 这样的乱码；对话页不再偶尔误弹“在等你选择”。
