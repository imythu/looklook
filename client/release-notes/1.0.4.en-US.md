Looklook client 1.0.4: fixes a blank page on startup, folder browsing errors and more.

- Fixed: if another program on your computer was already using port 1234, opening Looklook showed a blank page. Looklook now automatically picks the first free port among 1244, 1254, and so on, remembers it, and keeps using that address.
- Fixed: "Browse" in the new-terminal dialog failed with an error and couldn't list folders.
- Folders you don't have permission to open no longer show "Can't find folder". Instead you see why and how to grant access (macOS privacy settings, Windows security, and so on), with a Retry button, and you can still go up a level.
- On Windows, the system folders in your user folder that can't be opened (such as "Application Data" and "My Documents") are hidden by default; on macOS, hidden folders such as ~/Library are hidden by default.
- Opening Looklook twice no longer runs two copies; it opens the one that's already running.
- The bundled terminal component is now called looklook-term, so it's easy to recognize as part of Looklook in Task Manager and firewall prompts.
