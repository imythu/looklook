Looklook client 1.14.0: pick SSH key files directly and check them in a masked preview, connect through a jump host without entering a password or key, and maximize terminals.

- A Browse button next to an SSH host's key file lets you pick the key file on this computer instead of typing its path.
- Once a key is chosen (a file on this computer, uploaded, pasted or already saved), a masked summary is shown: algorithm and size, whether it has a passphrase, its comment and SHA256 fingerprint. Only the first and last few characters of the key are shown, so you can confirm it is the right one.
- With "System key" sign-in, the keys ssh will try (keys in ssh-agent and the default keys in ~/.ssh) are listed, also masked.
- New sign-in method "Via jump host": Looklook signs in to the jump host, then runs ssh there to reach the target host using the keys already set up on the jump host. Use it when the target's key lives on the jump host. No password or key is needed for this host.
- Terminals in the workspace can now be maximized to fill the browser window without going full screen. Double-click the empty part of the terminal's title bar to switch too.
