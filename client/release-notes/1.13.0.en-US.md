Looklook client 1.13.0: sessions are easier to find when you have many, the terminal works better on phones, and SSH hosts support uploaded keys and jump hosts.

- The sessions page has three views, switched at the top right: cards, list (one row per session, so many fit on one screen) and workspace (on a computer: open terminals as tabs on the left and a searchable session list on the right, like a terminal app; Alt+1…9 switches tabs). You can search sessions by name, folder or command.
- After a page reload, the terminals open in the workspace and your scroll position in the card and list views are restored.
- The terminal switcher bar at the bottom of the sessions page and the floating terminal windows are gone: "Open here" now opens the terminal in the workspace, or full screen on a phone.
- Terminal page on phones: the top bar now holds only back, name, upload, the key bar and "More", so buttons no longer cover each other. Terminal, Files and Git now switch from a tab bar at the bottom.
- Fixed: with the light or Agent terminal theme, the bars above and below the terminal stayed dark. The whole page now follows the terminal theme.
- SSH hosts can use a private key file on this computer (keys found in ~/.ssh are listed for you) or a key uploaded from your browser. Uploaded keys are stored encrypted on this computer, like passwords, and are never sent to Looklook's servers.
- SSH hosts can connect through a jump host: pick a saved host, or create the jump host while adding a host (the form tells you a second host will be created). Each hop uses its own password or key.
