Looklook client 1.12.2: fixes remote sessions that kept saying "This computer didn't answer in time" while the computer showed as online.

- Fixed: with Clash, Surge or another proxy in TUN (fake-ip) mode, the remote connection could end up half-broken after a few hours: the app said connected and the web page showed the computer online, but opening a terminal kept saying it didn't answer in time. Each connection now looks up the server address again instead of reusing a stale proxy address.
- When the remote connection can no longer open new connections, the app now notices on its own and reconnects within two or three minutes, so you no longer need to press "Reconnect now".
- A connection attempt that stalls is now given up and retried sooner instead of hanging.
