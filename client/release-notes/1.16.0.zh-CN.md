看看电脑端 1.16.0：对话能在 Codex、Claude Code、DSH 之间搬家，新增对话记录和聊天视图；本机网页可以临时分享给指定账号；修复 Windows 上终端反复重连。

- 搬家对话：在“终端”页点“搬家对话”，把 Codex 的对话搬到 DSH 或反过来，搬完可以直接在新工具里接着聊；原对话不会被改动。Claude Code 的对话也能搬入搬出。
- 对话记录：新增只读的对话记录页，可以搜索 Codex、Claude Code、DSH 的历史对话，一键在终端里继续，或者搬到另一个工具。
- 聊天视图：AI 终端可以在“终端 / 聊天 / 改动”之间切换。聊天视图用大白话列出 AI 做了什么并标出风险，屏幕上的确认提示变成按钮，点一下就能批准。会话列表显示“等你确认 / 工作中 / 空闲”，网页标题会显示有几个在等你。
- 输入框：在普通文本框里写好提示词（输入法、语音输入都能用），一次发到终端，可选自动回车；每个终端的草稿单独保存。
- 新增“DSH（终端）”会话类型；能自动找到 Claude 桌面版自带的 Claude Code 和 DSH 的安装位置，也可以手动指定程序位置。
- 本机网页可以临时分享给另一个看看账号（1 小时到 7 天），分享前会有安全提示；可以随时查看和撤销分享。
- 工作区侧栏按项目文件夹分组，每个项目一键新建终端或 AI 会话；终端菜单新增“复制终端”。
- 桌面版新增“本机 / 全部电脑”切换，在同一个窗口里打开个人地址。
- 修复 Windows 上工作目录较深、含中文或安装路径较长时终端一打开就崩溃、页面不停重连的问题。
- 修复接着之前的 Codex 对话继续时，Codex 报“无法使用共享后台服务”后退出的问题。
- 终端连接暂时不可用时显示提示，不再弹出浏览器登录框。
- 手机上对话记录页的排版修好了。
