看看电脑端 1.11.0：Claude Code、Codex 可以使用第三方模型服务商（中转站）。

- 新增“设置 → 模型服务商”：可以给 Claude Code、Codex 分别选择推荐的服务商（标有“推广”），或自己填写接口地址，再填入 API Key；之后新建或重启的终端就走这个接口。随时可以恢复官方接口。
- 第一次使用前需要阅读并同意免责声明：服务由第三方提供，对话与代码会直接发给所选服务商，费用与损失由你与服务商自行承担。
- API Key 只保存在这台电脑上（仅你本人可读），不会上传，也不会出现在任何进程的命令行参数里。Claude Code 走第三方接口时会清空 ANTHROPIC_API_KEY，你的官方 Key 不会被一起发出去；Codex 不改动你的 ~/.codex/config.toml 和 ChatGPT 登录。
- 新建终端时会显示这个终端将使用的接口，并可一键前往更改。
