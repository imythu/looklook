看看电脑端 1.58.0：在飞书里把别人反馈的问题转给 AI，会按是谁反馈的自动分到对应的项目，每个问题一个会话。

- 新增：转给机器人的问题（合并转发，或者“张三：……”这样开头的消息）不再塞进当前会话，而是各开一个新会话。项目按这个顺序定：消息里写的 #项目名 → 同一个人一天内的会话（接着说，可以点“当新问题”）→ 你设过的“以后这个人的都交给这个项目” → 这个人最近几次都进了同一个项目。都没有时出一张选择卡片，提到了哪个项目文件夹的名字会预先选好。转发时用“合并转发”（只有一条也行），能认出是谁说的。
- 新增：在消息里写 @codex 或 @claude 指定用哪个助手；发“结束”表示这件事办完了，下一句话开新会话。
- 新增：回答卡片上多了“回复对方”（AI 写好回复，装了飞书 CLI 时替你发出去，发之前问你）、“换项目”和“接到别的会话”。选项目时多了“杂事”，用来起草、翻译这类跟项目无关的事。
- 新增：群里 @ 机器人时，第一次会问这个群对应哪个项目，可以记住，以后不用再选。
- 变化：AI 助手以你本人的身份用飞书（看群聊和私聊、找人、读写文档、发消息），改为使用飞书官方的命令行工具 lark-cli：在“AI 助手”页一键安装，Claude Code、Codex 装好就会用，看看的飞书应用不用再开用户权限。原来的飞书 MCP 工具已去掉。
- 改进：AI 助手连上看看时拿到的说明按使用场景写，更容易在该用的时候用上本机网页和 SSH 工具。
- 修复：切换对话、终端、Git、文件时，标签组不再跟着挪；接着以前的 Codex 对话新建会话时终端是空的。
- 修复：Mac 上切换会话后，光标不进输入框。
- 修复：对话里自己发的图片一直转圈；添加项目的搜索框多了一层边框。
- 修复：终端四周有黑框，第一次打开时最下面两行被裁掉。
