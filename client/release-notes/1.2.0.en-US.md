Looklook client 1.2.0: Codex conversations, choose your shell, update from inside the client, report problems, and a better phone key bar.

- New: Codex conversations. Pick Codex when creating a session to give it tasks in a chat view, follow its commands, file changes and plan, and answer its questions or approve actions right in the page; opening it as a terminal still works. "My terminals" is now "My sessions".
- New: pick the shell when creating a terminal. On Windows the default is PowerShell 7, then Windows PowerShell, then cmd; you can also pick Git Bash, WSL or enter your own (e.g. bash). On Linux and macOS choose from bash, zsh, fish and other installed shells. Change the default in Settings.
- New: automatic update checks. When a new version is out you'll see a reminder in the menu and at the top of the page; dismiss it and that version won't remind you again. Click "Update now" to download, install and restart automatically; tasks running in your terminals keep running. You can also check manually in Settings → About.
- New: Settings → Problems & logs shows recent errors, and "Report a problem" sends us a description plus logs (you can preview everything first; keys and access codes are hidden automatically).
- Improved: the folder chooser is now a dialog, and on Windows you can switch drives under "This PC".
- Improved: the phone key bar can collapse to a single row, and "More" groups keys by Linux, macOS and Windows common shortcuts and AI assistants (Claude Code, Codex), with your computer's system first.
- Fixed: the Windows installer is now install.bat, so double-clicking runs it instead of asking which app to open it with.
- Fixed: on Windows, reopening a terminal after closing its page didn't reconnect to the same session. Note: background sessions created on Windows before this update need their terminals restarted once.
