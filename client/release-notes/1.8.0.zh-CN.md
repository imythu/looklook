看看电脑端 1.8.0：在自己电脑上远程打开时，终端自动直连，不再绕中转。

- 远程地址打开管理台时，如果浏览器就开在终端所在的这台电脑上，终端会自动直接连本机，不经过远程线路，打字几乎没有延迟。终端标题旁显示绿色的“直连”。
- 第一次直连时，新版 Chrome / Edge 会询问是否允许网页“访问这台设备上的应用和服务”，点“允许”即可；拒绝后会继续走远程线路，之后不再询问。只有电脑上的浏览器会尝试直连，手机不会弹出这个询问。
- 经远程线路连接时，终端标题旁会显示往返延迟（毫秒），偏慢时标成黄色；鼠标停在上面能看到延迟从哪来、怎么改善。
- 减少了终端在 macOS 和 Windows 上偶尔出现的输出卡顿。
