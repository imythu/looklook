LookLook desktop 1.45.0: preview office files in the file browser, and task templates for new sessions.

- New: preview PDFs, Word documents (.docx), Excel sheets (.xlsx, with multiple sheets) and CSV files in the file browser. Tables show column letters and row numbers for the first 500 rows, and CSVs can be switched back to the raw text. PowerPoint and older formats ask you to download them, and files over 20 MB aren't previewed here.
- New: task templates. Click “Templates” next to the input of a new session to fill in a common task (nothing is sent until you send it, so you can still edit it). Save your own text as a template too; templates are shared across your computers. Five examples are included the first time, such as tidying up spreadsheets or summarizing several documents on one page.
