看看电脑端的 Beta 版，已包含正式版 1.44.0 的全部内容，另外加了底部状态栏和几项用量、会话方面的改进，还可以在设置里选择接收 Beta 版。

- 新增：「设置 → 更新 → 接收 Beta 版」，默认关闭。打开后正式版和 Beta 版都会收到，安装版本号较新的一个；关闭后不会退回旧版本，待正式版的版本号超过当前 Beta 版时再更新到正式版。
- 新增：电脑上的底部状态栏，显示连接状态、有几个会话在运行、几个在等你回复，以及各账号 5 小时额度还剩多少（点开看什么时候回满、建议用哪个），颜色跟着当前标签走。
- 新增：新会话的类型菜单里分出「Codex 对话」和「Codex 终端」，每种后面写着额度还剩多少，选的那个快用完时会提醒。
- 新增：输入框旁的小圆环显示账号 5 小时额度还剩多少；手机上点圆环会从底部弹出额度面板。
- 新增：Git 标签里可以勾选文件直接提交，可选提交后推送；本次对话改过的文件单独列在前面。
- 改进：电脑上整个页面固定一屏，图标栏、会话栏和内容区域各自滚动，右边不再出现整块的滚动条。
- 改进：审批卡片只留「允许」「拒绝」两个按钮，带理由拒绝等放进「⋯」菜单；等待回复时更醒目。
- 修复：同时打开多个对话页时，实时推送占满浏览器连接导致页面卡住；现在只有正在看的对话页保持实时连接。
- 修复：连 OpenAI 超时时 Codex 的用量整个消失；现在沿用上次读到的，并标出是几分钟前的数据。
- 修复：Claude Code 对话页偶尔一直显示一条早就发出去的「排队中」消息。
