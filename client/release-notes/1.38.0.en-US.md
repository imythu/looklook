Looklook desktop 1.38.0: settings sync across your computers, and first-time Claude Code setup no longer needs the terminal.

- New: color scheme, font, font size, default AI session permissions and attachment retention now sync automatically across your computers. Change one and the others follow. Sync data goes directly between your computers and is never stored on the server. Turn it off under Settings → General → Settings sync; synced options are marked with an icon.
- New: when Claude Code starts for the first time from the chat page, the theme picker and security notes are skipped automatically (theme follows the terminal). The "trust this folder" and Bypass Permissions confirmations appear as dialogs on the page, in your interface language, so you no longer have to switch to the terminal.
- Improved: remote access to your computer is faster. Responses are compressed, so pages load noticeably faster over relayed connections, and reloading connects right away without waiting for the device list.
- Improved: the default terminal color scheme is now Tangerine. If you were on the old default (Lagoon) it switches once; picking Lagoon again afterwards sticks.
- Fixed: on Windows, messages, Enter and Esc sent from the chat page were sometimes swallowed (text stayed in the input box, dialogs would not close).
- Fixed: with a long session title, or a narrow terminal on a phone, the chat page kept showing "waiting for your choice".
