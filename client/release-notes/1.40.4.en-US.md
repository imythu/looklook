LookLook desktop 1.40.4: each project now lists your past Claude Code, Codex and OpenCode conversations, one click to continue; when you hit a usage limit you can switch accounts and keep going.

- New: under each project in the sidebar, besides running sessions, you now see the most recent past conversations in that folder; click one to continue it. Projects can be pinned, projects unused for a month fold away when you have many, and search finds conversations too.
- New: project page. Open it with "All N sessions" under a project to filter by tool, browse by date, load older ones as you scroll, search full text with Enter, and hide conversations you don't need.
- New: Add project. It lists the folders on this computer that already have conversations, so you just tick them; you can also paste a path or browse.
- New: when Claude Code hits its usage limit, the waiting card offers "Continue with another account", picking up the same conversation.
- Fixed: the usage-limit card stayed on screen after cancelling, resetting or rerunning.
- Fixed: with only one computer, "Choose another folder" in a new session did nothing.
- Fixed: on Mac, when opened from the Dock, the Codex chat view couldn't connect or said Codex wasn't running (Codex installed with nvm, npm or Homebrew).
- Fixed: no more "quit unexpectedly" after restarting macOS; toasts on phones now show at the top and can be tapped or swiped away; adding an official Claude account no longer asks for a name first.
