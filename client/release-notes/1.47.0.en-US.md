LookLook desktop 1.47.0: multiple Codex profiles, one-step setup for popular providers, and a usage and cost overview.

- New: Settings → AI agents → “Codex profiles”. Besides Codex's own sign-in, you can add several third-party endpoints and pick a default; new sessions can choose another, and existing sessions keep theirs. Each endpoint can set a model, and the model menu in chat lists that provider's own models.
- New: “Popular providers” when adding a third-party endpoint: DeepSeek, Zhipu GLM, Kimi, MiniMax, Alibaba Cloud Model Studio, Volcengine Ark, SiliconFlow, Xiaomi MiMo, OpenRouter, Anthropic API, OpenAI API, plus several coding plans. Pick one and paste your API key; the endpoint is filled in, and you can choose from the provider's current models with prices shown. Works for both Claude Code and Codex.
- New: Settings → AI agents → “Usage”. See how many tokens Claude Code and Codex used on this computer, with costs estimated at each provider's public API prices: totals for today and the last 7 / 30 / 90 days, cost per day, and a per-model breakdown. Prices are refreshed daily from models.dev. Everything is counted on your computer and nothing is uploaded. Subscriptions and coding plans aren't billed this way, so read it as an equivalent value.
- Improved: Claude Code third-party endpoints accept Anthropic's own API keys (sk-ant-api…), without the “use this API key?” prompt at startup.
- Changed: “Model providers” is now part of “Codex profiles”. Your previous choice moves over automatically and becomes the default.
