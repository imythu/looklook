看看电脑端 1.9.0：电脑离线马上知道，多台电脑更好切换，AI 输入框能换行了。

- 电脑断网或看看退出后，远程页面很快显示“电脑不在线”，不再一直转圈；电脑重新上线后页面会自动打开。
- 右上角“远程访问中”旁显示往返延迟（毫秒），偏慢时变成黄色或红色。
- 登录了好几台电脑时，右上角有一个写着电脑名的按钮，点开能看到每台电脑是否在线并切换；第一次会提示它在哪里。
- 在 Claude Code、Codex、OpenCode 里按 Shift+Enter 换行，Enter 发送；手机按键条上先点 ⇧ 再点回车也是换行。
- 在 Windows / Linux 上用 Ctrl+V 粘贴文字时，Claude Code 不再提示“No image found in clipboard”。
- 一键安装 Codex、Claude Code、DSH 等工具改在后台进行，进度直接显示在新建窗口里，不再多出一个“安装”终端。
- 修复打开 DSH 时提示“dsh web authentication required”。
- 修复远程页面上网络抖一下，打开着的终端小窗就不见了。
