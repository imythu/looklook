Looklook client 1.9.0: know right away when a computer goes offline, switch computers more easily, and add new lines in AI prompts.

- When a computer loses its network or Looklook quits, the remote page shows "Computer is offline" soon instead of loading forever, and opens again by itself once the computer is back.
- The "Remote access on" badge at the top right now shows the round-trip delay in milliseconds, in amber or red when it's slow.
- With several computers signed in, a button with the computer's name at the top right shows which ones are online and lets you switch; a tip points it out the first time.
- In Claude Code, Codex and OpenCode, Shift+Enter adds a new line and Enter sends. On phones, tap ⇧ on the key bar, then Enter.
- Pasting text with Ctrl+V on Windows and Linux no longer makes Claude Code say "No image found in clipboard".
- One-click installs of Codex, Claude Code, DSH and other tools now run in the background with progress shown in the new-session window, instead of leaving an extra "Install" terminal behind.
- Fixed "dsh web authentication required" when opening DSH.
- Fixed embedded terminal windows disappearing from the remote page after a brief network hiccup.
