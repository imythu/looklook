看看电脑端 1.40.0：新建 Claude Code 对话不再一上来就问一堆问题，Claude Code 账号能直接查用量。

- 改进：第一次用 Claude Code、或者在新的文件夹里开对话时，不再弹选主题、安全提示、“信任这个文件夹吗”、全部权限警告，直接就能开始聊。在家目录里开对话也不会每次都问是否信任了。主题默认跟随终端，你自己选过的主题不会被改。
- 新增：「Claude Code 账号」里已登录的账号可以点「查用量」看剩余额度，不消耗额度；「重新登录」移到了更多菜单里。登录已经失效时会标出来，提示你重新登录。
- 改进：远程打开或能切换电脑时，“发现新版本”“正在更新”“已更新”的提示前面会写明是哪台电脑。
