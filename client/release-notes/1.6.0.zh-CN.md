看看电脑端 1.6.0：服务器上也能扫码登录，远程线路可以自己选，新增 OpenCode 与 DSH。

- 新增：在没有图形界面的服务器上运行 looklook login，终端里会显示二维码，用手机扫码批准即可登录；按 Ctrl+C 取消。已经登录时直接显示当前账户。
- 命令行的帮助与提示改为中英双语；新增 looklook upgrade，等同于 looklook update。
- 新增“远程线路”（在“账户”页）：默认自动选择；觉得远程打开慢、打字卡时，可以测速后选一条延迟更低的线路，选择会被记住，立即生效。
- 新增 OpenCode 终端类型：一键启动（可选“全部权限”），没装时可一键安装，也可以一键接入看看的 MCP。
- 新增 DSH（DeepSeek Harness）：每台电脑一个，用它自己的网页界面，作为本机网页打开，本机和远程是同一个地址。OpenCode 与 DSH 的支持是新加的，遇到问题请在“设置 → 问题与日志”里反馈。
- 手机键盘：打开终端时不再自动弹出软键盘，点终端或按键条上的 ⌨ 才弹出；按键条在小屏幕上自动收成一行，横屏时隐藏标题栏；回车键常驻，按键大小随屏幕调整。
- 终端标题栏的“上传”按钮更显眼，第一次使用时有提示；发给 Codex、Claude Code 的文件按各自的习惯粘贴（图片显示为 [Image #N]，其他文件为路径）。
