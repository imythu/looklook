看看电脑端 1.44.1：少打扰的通知、安全网，Codex 对话页更省心。

- 新增：通知勿扰时段（按每台电脑的本地时间），时段内不发，结束时汇总成一张；“做完了”可以攒 10/30/60 分钟合成一张，出错和等你处理照常立即发。
- 新增：AI 正在干活但很久没有进展时提醒你一次，飞书里可以直接停止。离开 30 分钟以上回来，看板顶上显示这段时间做完、出错、在等你的数量。
- 新增：安全网。强推、硬重置、删整个家目录、删库这类做了很难挽回的命令，执行前要你确认（全部权限模式下也生效），也可以加自己的拒绝规则；在设置“AI → 安全网”里管理。
- 新增：每轮开始时自动给工作区存一个检查点（包括还没提交的改动），在终端的 Git 标签里能看之后改了什么，一键回到那一轮之前。
- 新增：智谱 GLM、Kimi、MiniMax 等第三方接口可以查 5 小时 / 每周用量；检测到本机 Ollama 时，一键把它设成 Claude Code 的接口。
- 新增：“本机网页”页列出这台电脑上正在监听的端口，认得 OpenClaw、Hermes 和常见开发服务器，一键转成网页在外面打开。
- 新增：安装密钥。云服务器、开机脚本、Docker 里装看看时，用电脑页生成的密钥直接登录，不用扫码。
- 改进：Codex 对话页能处理终端里 Codex 启动时的提示：新文件夹不再卡在“要不要信任这个文件夹”；有待确认的 hook 时在对话页列出来，可以信任或跳过；还没登录时提示到终端里登录；已归档的会话能直接接着聊。
- 改进：Codex 有新版本时在对话页提示，用 npm 装的可以一键更新，对话空闲时自动换成新版本；终端里的 Codex 不再弹更新提示卡住。
