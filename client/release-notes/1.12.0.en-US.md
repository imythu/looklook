Looklook client 1.12.0: file management, Git and SSH hosts, plus a smoother terminal.

- New Files page: browse files on this computer, preview text, images and Markdown (rendered), upload, download, create folders, rename and delete. Drop files onto the list to upload.
- The terminal page now has Terminal / Files / Git tabs. The Git tab shows the current branch, changes and history; click a file or commit to see the diff, and stage, commit, fetch, pull (fast-forward only) and push.
- New SSH hosts: save the servers you use and open an SSH terminal in one click, without typing passwords. Passwords are encrypted on this computer only and handed to ssh by Looklook — never shown and never in the terminal. For hosts you mark “Let AI assistants use this host”, Claude Code and Codex can run commands through MCP without ever seeing the password or key.
- Screenshots you paste into a terminal now show as thumbnails in the corner — click to view or delete. Settings → Pasted images & attachments lets you browse, delete or clear them and choose how long they’re kept (7 days by default).
- New terminal switcher at the bottom of Sessions: click to open or bring a terminal to the front, click again to minimize, or press Alt+1…9.
- Select text in a terminal and a Copy button appears next to it; Ctrl+Shift+C also works on Windows / Linux.
- Fixed: full-width Chinese brackets （） and some other Chinese punctuation couldn’t be typed with Chinese input methods.
- More reliable remote access: reconnects right away after this computer wakes up or changes networks. The top bar shows the remote connection status with a “Reconnect now” button.
- Fixed: the Mac app could show as offline when opened from your personal address while running only in the menu bar.
- The default terminal colors are now a softer, warm “Agent” dark theme; the previous dark and light themes are still available in Settings.
