Looklook client 1.3.2: fixes terminals that could not be opened on Windows after an in-app update.

- Fixed: on Windows, after updating inside the app, opening a terminal could fail with "psmux: failed to create session". Updating to this version repairs it automatically, and terminals that were running before the update can be opened again.
- Fixed: future in-app updates on Windows no longer break terminals that are running while the update installs.
