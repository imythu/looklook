Looklook desktop 1.30.0: Codex chats are now driven directly by Looklook, with model selection, account usage and generated images shown right in the conversation; Claude usage now matches the Claude app.

- Codex chats now run through Codex's app-server: replies stream in as they're written, approvals and questions are answered in the chat, and you can add a message or stop while it works. The Terminal tab is a plain terminal in the same folder. Codex sessions that were already open in a terminal pick up their conversation automatically when you open the chat.
- In Codex chats you can pick the model and thinking effort, and the Usage panel shows the account, plan, 5-hour and weekly limits, and context use.
- Images Codex generates appear right in the conversation (on phones too). Each image has its own link you can open, copy or download, and a new Resources panel lists the conversation's generated images plus the web pages and searches it used.
- Files Codex produces (new or edited files, PDFs, spreadsheets, videos and so on) are listed in the Resources panel, where you can open, copy a link to or download them; paths to these files in its replies are clickable too.
- Claude Code usage is now fetched live and matches the Claude app and /usage, instead of showing numbers from days ago.
- When Claude Code shows a choice dialog, picking an option or closing it from the chat view is more reliable, and pressing Stop after it has finished no longer opens the rewind menu by mistake.
- On Windows, stray text like `[<35;45;31M` no longer shows up in the Codex input box, and the chat view no longer occasionally pops up "Waiting for your choice" by mistake.
