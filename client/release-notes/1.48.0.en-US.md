LookLook desktop 1.48.0: DSH opens right in its session tab, Codex supports Git worktrees, and device selection and history work better.

- New: In Codex conversations, /new in a Git repository first asks where the new conversation should run, and can create a separate Git worktree. /worktree continues the current conversation in a new worktree, starts a new one there, or switches back to a conversation in an existing worktree. Worktrees are shared with the ones Codex creates in its terminal UI.
- New: On macOS, Settings can grant access to Desktop, Documents, Downloads and other common folders in one go, and open the Full Disk Access settings directly.
- Improved: DSH sessions open their web UI right in the session tab, including over remote access, and can still be opened in a browser.
- Improved: History shows this computer first, loads more as you scroll, and searches conversation contents automatically. Double-click or press Enter to continue a conversation.
- Improved: When you create a session and DSH, Codex, Claude Code or OpenCode isn't installed, LookLook guides you to install it.
- Fixed: On desktop, the input box sometimes sat far above the bottom of the window, and it didn't get focus when it should.
- Fixed: On phones, the bottom of the Me menu was cut off.
- Fixed: The selected computer wasn't remembered and often switched to another one, and update notices didn't say which computer they were for.
- Fixed: After a macOS auto-update, macOS asked again for file access you had already granted (fixed for updates after this version).
