看看客户端 1.0.1 测试版：更安全的登录与访问方式，桌面端更省心。

- 登录改为在浏览器里确认：客户端显示一个确认码，在网页上点“允许”即可，不再在客户端里输入密码。
- 访问控制：可选择允许同一 Wi‑Fi 里的设备、或指定的 IP 打开管理台，并可设置访问码；这台电脑自己打开无需访问码。NAS 等没有桌面的机器可用 looklook access 命令设置。
- “在手机或另一台电脑上打开”卡片新增二维码，并可在“随处可用”（专属地址）与“同一 Wi‑Fi”（局域网地址）之间切换。
- 新建终端时可用文件夹选择器选目录；Codex、Claude Code 可勾选“以全部权限打开”；终端可直接嵌入页面查看，运行记录更清楚。
- Windows 与 macOS 新增托盘图标：打开、启动、停止、退出、开机自启；Windows 不再留下黑色命令行窗口。
- 手机上的多处显示问题已修复（文字被挤成一列、按钮溢出等）；运行中的终端不能被误删。
- 安装包体积更小，并加强了防调试与完整性保护。
- 仍未做代码签名：Windows 与 macOS 首次运行需要手动放行，步骤见“下载”页。
