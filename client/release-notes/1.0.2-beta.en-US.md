Looklook client 1.0.2 beta: see the remote tunnel's connection status, and a friendlier start for beginners.

- New remote tunnel status: the home and account pages show "Connecting / Connected / Failed". When it fails, plain-language text explains why (network down, DNS failure, blocked, sign-in needed again, and so on) and what to do, with technical details you can expand.
- Opening a terminal shows a "Connecting to the terminal…" animation; if a terminal drops, a banner says it is reconnecting automatically and tells you when it is back.
- "Open here" now opens a draggable, resizable floating window instead of taking up space in the page.
- The tray menu is grayed out by service state: while running only "Open dashboard / Stop service" are available, and while stopped only "Start service".
- The client icon is now green, so it is instantly distinguishable from the indigo cloud website icon.
- Fixed: switching language in Settings did not change the interface, and the terminal appearance preview did not follow the language. The English interface is now fully translated.
- When you have no terminals yet, the home page shows a three-step getting-started guide.
