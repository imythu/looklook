LookLook desktop 1.40.0: new Claude Code conversations start right away without a round of questions, and Claude Code accounts can check their usage.

- Improved: the first time you use Claude Code, or open a conversation in a new folder, you no longer get the theme picker, the security notes, "Do you trust this folder?" or the full-access warning; you can start chatting right away. Conversations in your home folder no longer ask about trust every time either. The theme follows your terminal by default, and a theme you chose yourself is left as it is.
- New: signed-in accounts in Claude Code accounts have a Check usage button that shows the remaining quota without using any of it; Sign in again has moved to the more menu. An account whose sign-in has expired is marked, with a prompt to sign in again.
- Improved: when you open a computer remotely or can switch between computers, the "New version available", "Updating" and "Updated" notices say which computer they are about.
