Looklook desktop 1.33.0: Settings, Computers, Account and Membership now slide in as a drawer so you never leave the session you're in; terminals stay readable while a computer is offline and reconnect by themselves; creating a session is smoother; macOS stops asking for folder access after every upgrade.

- Settings, Computers, Account and Membership slide in from the right while the session and its terminals stay connected behind them. Close with Esc, a click outside or the browser's back button, and you're back in the session's input box. On phones the drawer is full screen and the back gesture closes it.
- When a computer goes offline, its terminal tabs stay open and readable with a note that input is unavailable; when the computer is back, the terminal reconnects right away.
- "Update now" no longer blocks the whole page: close the dialog and let it update in the background, with progress in the banner at the top. If the restart takes too long, you can reload the page.
- Creating a session: choosing "Full access" no longer needs a separate root confirmation; only the tool types you use most are shown, the rest are under "More"; if a tool isn't installed yet, Start installs it first (with a choice of npm mirror) and then starts. When Start is unavailable, the reason is shown next to the button.
- Chat view: tool call parameters are listed one per row, JSON is formatted and can be copied, and links are clickable; when parameters were cut short, you can load them in full.
- The reply suggestion Claude Code shows in the terminal's input box after a turn now appears in the chat view too; click it or press Tab to fill it in.
- The account menu can copy your personal remote address in one click, and the Remote access card shows the address even when collapsed.
- macOS: from this version on every release carries the same signature, so future upgrades no longer ask again for access to Documents, Desktop and other folders (upgrading to 1.33.0 asks one last time).
- Linux: auto-updates now keep the program in the data directory, so in Docker mapping just the data directory is enough to keep auto-updates.
