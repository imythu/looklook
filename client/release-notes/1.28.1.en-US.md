Looklook desktop 1.28.1: start a session right from the tab bar, find Docker containers faster, and browse folders inside containers.

- The session tab bar has a "+": it opens the new-session box with the current session's computer and folder already chosen (the same container for container sessions).
- The start page has a "Docker" button under the input box that lists the running containers on that computer, no more digging through the project menu.
- Folders inside a container can be browsed, picked and created just like regular folders; a missing folder is created when the session starts.
- Fixed: choosing a type on the start page (e.g. Codex) and then switching project or computer no longer resets it to that project's last type.
