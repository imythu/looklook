Looklook desktop 1.32.0: import SSH hosts straight from another computer, passwords and private keys included; the console on computers drops the full-width top bar for a tidier sidebar; the Codex terminal is more robust.

- SSH hosts: on a new computer, open SSH Hosts and click "Import from another computer", pick the old computer and the hosts, and they come over with their passwords and private keys. Jump hosts they use come along automatically, and name clashes can be skipped, overwritten or renamed. Each host is tested after import. Both computers need 1.32.0 and the same account.
- Imports must be confirmed on the old computer: the new one shows a 6-digit code, and nothing is exported until you enter it in the notice at the top of Looklook on the old computer. Passwords and keys travel encrypted directly between the two computers; the Looklook server and relays can't see them. Imported hosts are not available to AI assistants by default, and both computers keep a record. If you can't get to the old computer, turn on "Allow confirming SSH exports remotely" there; remote confirmation also needs an email code.
- The console on computers no longer has a full-width top bar: the logo sits at the top of the sidebar, and the connection status and language switch at the bottom. Click the logo to expand a collapsed sidebar. Phones are unchanged.
- Codex: the terminal reconnects by itself after a drop; when the chat view can't reach Codex for a while, the terminal keeps working; switching to a Codex session no longer shows it as Claude Code first; sidebar info such as usage retries on its own when it can't load.
- Codex and Claude Code: when a terminal session wasn't started by Looklook, the chat view now says so instead of getting stuck; Codex supports /new to start a new session.
- In Docker, the --local-from start option (or LOOKLOOK_LOCAL_FROM) lets the host count as "this computer", so settings that can only be changed locally can be changed from the host's browser.
