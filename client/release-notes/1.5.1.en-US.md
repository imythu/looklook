Looklook client 1.5.1: fixes in-app updates from older versions failing on Windows.

- Fixed: on Windows, updating inside the app from older versions such as 1.3.2 to 1.5.0 failed with "Installing the update failed; your current version is unchanged. (Access is denied. (os error 5))". You can now update to this version inside the app.
- Future in-app updates on Windows no longer fail when antivirus or another program briefly holds a file; if an update does fail, the message names the file.
