看看客户端首个测试版。

- 登录看看账户后，在手机或任意浏览器通过专属地址打开这台电脑上的终端；关掉网页，终端里的任务照样运行。
- 终端数量不限，可选普通终端、Codex、Claude Code 或自己输入命令；Codex、Claude Code 没装时可一键安装。
- 内置离家访问通道，无需公网 IP 或额外配置。
- 本机网页：把电脑上的开发网页（如 localhost:5173）放到专属地址下，最多 10 个。
- 内置终端字体（JetBrains Mono 与霞鹜文楷等宽），深浅两套配色；手机端带 Esc、Tab、方向键、Ctrl 组合键按键条。
- 支持 Linux（x86_64 / ARM64）、macOS（Apple 芯片）、Windows（x86_64）。Windows 上关掉终端页面后程序随之结束。
- 安装包尚未做代码签名：Windows 与 macOS 首次运行需要手动放行，步骤见“下载”页。
