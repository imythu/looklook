看看电脑端 1.27.0：Codex 会话也有“对话”界面了，Windows 上的 Codex 也能正常启动。

- Codex 会话多了“对话”标签：回复、运行的命令和输出、改动的文件都整理成卡片，和 Claude Code 的对话界面一样；已有的 Codex 会话升级后自动打开，下次启动会话时生效。
- Codex 要运行命令、改文件时，在对话里点“允许 / 拒绝”；信任文件夹、Codex 自己的选择框也直接在对话里选，不用切到终端。
- 开启对话界面之前就在运行的 Codex，对话里会提示“没有接入对话界面”，可以一键重启并接入。
- 对话模式的 Codex 用看看自己的配置（`~/.codex/looklook-chat.config.toml`）带上需要的 hooks，你自己的 Codex 配置不会被改动。Codex 对话里暂时不能发图片、选模型和权限模式，这些仍在终端里操作。
- 修复 Windows 上 Codex 终端打不开、提示“无法加载文件 codex.ps1”的问题（PowerShell 默认不让运行脚本，现在直接启动 codex.exe）。
- 修复对话里同一张工具卡片重复出现、并行的工具调用有一张一直在转的问题。
- 电脑上只装了 Claude 桌面版时，新建 Claude Code 会话会自动使用桌面版自带的 Claude Code。
