看看电脑端 1.15.0：添加 SSH 主机时就能测试连接，失败时说清原因；新增“AI 助手”页，AI 能用哪些工具一目了然。

- 添加或修改 SSH 主机时，可以在保存前点“测试连接”；新添加的主机保存后也会自动测试一次。
- 测试失败时会标出卡在哪一步（建立连接、SSH 握手、登录、运行命令），说明原因和解决办法，比如地址解析不了、端口被拒绝、密码不对、服务器不接受这种登录方式、私钥权限不对等，并附上完整日志方便排查。
- 修复连接 Windows 服务器时测试连接总是失败的问题；连接 Windows 服务器失败时还会给出 Windows 专门的提示。
- 新增“AI 助手”页：MCP 接口的设置从“本机网页”移到了这里，并列出 AI 助手能用的全部工具；可以一键关闭 AI 使用 SSH 主机，也可以逐台开关。
- SSH 主机卡片上可以直接切换“允许 AI 助手使用”，不用再进修改页面。
