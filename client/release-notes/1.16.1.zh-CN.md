看看电脑端 1.16.1：修复 macOS 桌面版打开 DSH、点“新窗口打开”时崩溃；可以把看看装进 Docker 容器；终端显示和停止更可靠；撤下 1.16.0 的对话搬家、对话记录和聊天视图。

- 修复 macOS 桌面版启动打开 DSH、点终端右上角“新窗口打开”时应用直接崩溃的问题。
- 可以把看看装进正在运行的 Docker 容器：在 Docker 主机上运行下载页给出的命令即可，容器里不需要 curl；用 sudo 运行时会在主机上装好服务，主机重启、容器重启后自动启动。
- 进入会话页后自动聚焦当前在前台的终端，打开就能直接输入。
- 窗口切回来时终端会重新排版并完整重绘，不再出现只画了一半（比如 AI 的输入框不见了）。
- 停止终端时会结束它启动的所有程序；删除正在运行的终端会先停止它，不再拒绝删除。
- 新增“选择文字”视图（顶栏按钮，手机上长按），以普通文字显示最近约 3000 行，方便选择和复制；浏览器拦截终端复制时会给出“复制”按钮。
- 手机上在终端里快速滑动更流畅，不再卡住一阵。
- 新建终端的默认名称带上文件夹名，例如“my-app · Claude Code”。
- 撤下 1.16.0 的对话搬家、对话记录页和聊天视图。输入框、“DSH（终端）”会话类型、网页临时分享等其他功能不受影响。
- Linux 上没有 systemd 时重新运行安装命令也能正常升级。
