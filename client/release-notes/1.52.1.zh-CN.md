看看电脑端 1.52.1：DSH 端口被占用时也能打开；⌘W / Ctrl+W 关闭当前标签；复制会话回到开新会话。

- 修复：DSH 的端口被别的程序占着时，DSH 起不来，页面一直停在“拿到启动口令”。现在会发现 DSH 已经退出、自动换一个空闲端口重新运行，诊断信息里也写明是哪个程序占着端口。
- 新增：⌘W（Mac）/ Ctrl+W 关掉当前会话标签。焦点在终端里时，Ctrl+W 照旧是终端里的删词；Mac 桌面版在终端里也能用 ⌘W 关标签，关闭窗口改为 ⇧⌘W。
- 改进：“复制会话”改回新开一个同样设置的空白会话。想接着原来的对话换个方向试，用新的“复制一份接着聊”（只在聊过的 Claude Code / Codex 会话上有）。1.52.0 的更新说明里写的“复制会话会连对话一起复制”不再适用。
