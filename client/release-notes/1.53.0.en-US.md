LookLook desktop 1.53.0: DSH uses the one you already have running and opens more reliably remotely; the remote console connects even when UDP is blocked; see every step of a subagent in chat.

- Improved: When DSH is already running on the computer (started by you in a terminal, or the DSH desktop app), LookLook now uses it instead of starting another one, and leaves its port and settings alone. LookLook only starts DSH when none is running.
- Improved: Opening DSH in a browser remotely now goes through the same encrypted connection as the remote console instead of a web mapping, so it opens faster and more reliably. New DSH sessions no longer create a web mapping, and ones created earlier are removed automatically.
- Improved: After DSH restarts on a different port, opening it in LookLook reconnects right away.
- New: When a company network or security software blocks UDP, the remote console automatically connects to the route over TCP; the route is marked "via TCP".
- New: A collapsible tip under remote routes explains how to keep routes direct while a proxy app runs in TUN or global mode, with copyable Clash / mihomo rules.
- New: The public IPv4 / IPv6 in Direct connection settings can be a domain name (DDNS); LookLook resolves it periodically.
- New: Subagents in chat can be opened in the side panel to see each step; running subagents are shown above the input box.
- New: Opened files show line numbers and highlight the lines that were read or changed; files in chat can be flipped through with ← →; expanding a background task shows the full command, ready to copy.
- Improved: Claude and Codex account emails in Usage are masked by default; click the eye icon to show them.
- Fixed: After a Claude Code subscription expired, you couldn't switch accounts and continue; /new in chat didn't use the new default account.
- Fixed: "Only this one" in the computer filter popup was covered and couldn't be clicked.
