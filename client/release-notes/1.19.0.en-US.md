Looklook desktop 1.19.0: a much better Claude Code chat view, so common actions no longer need the terminal.

- New Tasks panel: see every subagent in the session (state, steps, what each step did) and background commands (output, one-click stop)
- When commands or subagents are still running in the background, the status line and the end of the chat say so, so "1 shell still running" no longer goes unnoticed
- Switch model, thinking effort and permission mode right below the input box
- Pickers and dialogs that need the terminal now open it below the chat and hide it again when you're done, instead of switching tabs; drag the divider to resize
- Fixed the chat jumping back up while output streams in, after you had scrolled to the bottom
- Consecutive tool calls of the same kind (reading, searching, editing, running commands) are grouped into one collapsed row; expand it to see each call
- Fixed the start of a message sometimes getting lost when sent right after a slash command
