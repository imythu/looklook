Looklook client 1.15.0: test SSH hosts while adding them, with clear reasons when a connection fails, and a new AI assistants page that shows which tools AI can use.

- When adding or editing an SSH host, click "Test connection" before saving. New hosts are also tested automatically after they are saved.
- When a test fails, it shows which step failed (connect, SSH handshake, sign in, run command) and explains the cause and what to do, such as an address that can't be resolved, a refused port, a wrong password, a sign-in method the server doesn't allow or wrong key file permissions. The full log is included for troubleshooting.
- Fixed the connection test always failing for Windows servers. Failures on Windows servers now come with Windows-specific hints.
- New AI assistants page: the MCP interface settings moved here from Local pages, along with a list of every tool AI assistants can use. Turn off SSH access for AI with one switch, or allow it host by host.
- SSH host cards now have a "Let AI assistants use" switch, so you no longer need to open the edit dialog.
