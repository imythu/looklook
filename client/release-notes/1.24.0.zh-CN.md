看看电脑端 1.24.0：Claude Code 的对话界面重新设计（Beta）。

- 对话页里不再弹出终端。Claude Code 弹出的选择框（比如切换模型确认）直接显示成对话页里的弹窗。
- 模型菜单列出你的账号实际能用的模型，打勾的是最近一条回复真正用的模型；每个模型可以单独选思考强度。
- 审批、提问、计划确认都在对话里完成；计划不满意可以直接写下要改什么，让 Claude 重新写。
- 新的输入框：权限模式（Shift+Tab 切换）、模型和思考强度、上下文用量圆环；输入 / 打开命令菜单。
- 右侧面板查看改动、子代理和后台命令、用量和额度、权限规则和 MCP 服务器。
- 对话界面还是 Beta 版，有做不了的，随时可以切到“终端”标签用完整的 Claude Code。
