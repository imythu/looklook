LookLook desktop 1.52.0: Codex chats name themselves and ask questions with choice cards, file reads in chats preview inline, plus a batch of fixes.

- New: Codex chats started from the chat view now get an automatic name, shown in the session list and the chat header (previously only Codex in the terminal did this).
- New: When Codex asks you to choose, it shows a choice card instead of a plain-text list of options.
- New: "Read file" cards in chats expand into a preview. Images show a thumbnail that opens a viewer with zoom and download; code, documents and spreadsheets can be previewed in full or opened full screen.
- New: In the session list, finished sessions show a blue dot and sessions that exited with an error show a red dot.
- New: macOS menu shortcuts: ⌘, for Settings, ⌘N for a new session, ⌘R to reload, and ⌘+ / ⌘- / ⌘0 to zoom.
- New: Starting DSH shows progress for each step, and if it fails you can copy diagnostics with one click to send us.
- Improved: Deleted sessions disappear from the list right away, and duplicating a session also copies its conversation.
- Fixed: No "Switch account and continue" button appeared when a Claude Code account expired or was rejected.
- Fixed: Pressing Enter after typing English with a Chinese input method sent the message.
- Fixed: After a restart, the Claude Code chat view didn't continue the previous conversation.
- Fixed: The Codex chat view and Codex in the terminal could show different conversations.
- Fixed: Deleted sessions were sometimes left running in the background; they are now cleaned up periodically.
