Looklook desktop 1.37.0 brings livelier terminal colors and lets you view images you sent in chat.

- New: four terminal color schemes: Lagoon (deep blue, the new default), Sunset (plum), Mint (light mint) and Tangerine (cream with orange). Switch in Settings → Terminal → Color scheme; the existing Agent, Dark and Light schemes are still there. If you were on the old default (Agent), you are moved to Lagoon; pick Agent again in Settings to go back. Applies to terminals opened or restarted after the change.
- New: images you send in a Claude Code chat show as thumbnails; tap one to view it full screen, and swipe or use the arrows when a message has several.
- Improved: on the Chat, Changes and Files tabs, the top bar and bottom tab bar now match the page (light, or dark in dark mode) instead of staying black.
- Improved: when the computer goes offline, the chat no longer shows a dark banner over your messages; a small line above the input box says so instead. The terminal's offline notice is restyled and follows the terminal colors.
