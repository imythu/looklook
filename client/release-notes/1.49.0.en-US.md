LookLook desktop 1.49.0: chat with Claude Code and Codex right from Feishu (Lark).

- New: Chat with AI in Feishu. Send the bot a message and pick a computer, a folder, and Claude Code or Codex, and a session starts on that computer. The AI's reply streams into a card. When it needs your approval or a choice, the card arrives in the same thread. Reply in the thread to keep going, and use Stop on the card to interrupt a turn.
- New: You can send images and files to the AI. Files it writes during a turn (images up to 10 MB, other files up to 30 MB) are sent back to the thread.
- New: Start a new session with the New session button on a card, the bot's New session menu item, or by sending /new followed by your message. The bot's Sessions menu lists running sessions so you can continue them in Feishu. Tasks opens the Tasks page.
- New: You can also @ the bot in a group chat (turn this on separately). It only answers you, the bound user, and ignores @ mentions from anyone else.
- This is off by default. Turn on "Chat with the AI in Feishu" in Settings → Notifications. Sessions started from Feishu never use full access.
- To use these features, add the cardkit:card:write, im:resource and im:message.group_at_msg:readonly permissions to your app on the Feishu Open Platform, subscribe to the application.bot.menu_v6 event, set up the bot menu (new, sessions, tasks) as described on the settings page, and publish a new app version.
