A beta of the new Looklook desktop interface, including the fixes from stable 1.40.1 and 1.40.2: a refreshed interface with a status bar and command palette, and you can now opt in to beta versions in Settings.

- New: "Settings → Updates → Get beta versions". When on, you get both stable and beta releases and install whichever is newer. Turning it off won't roll back; you'll move to the stable release once its version passes the beta you're on.
- New: a status bar at the bottom shows how many sessions are running or waiting for you, and how much of each account's limit is left. It follows the current tab's colors. Press Ctrl+K for the command palette to jump to sessions, pages and common actions.
- New: starting a session is now a "Start with" list. Codex is split into "Codex chat" and "Codex terminal", and each tool has its own color.
- New: a small ring next to the input shows how much of your 5-hour limit is left; tap it for the 5-hour and weekly limits. On phones, tapping the ring opens a usage panel from the bottom, the "Start with" list shows what each tool has left, and the menu lists every account's limit at the bottom.
- New: commit selected files right from the Git tab, optionally pushing afterwards. Files changed in this conversation are listed first.
- Improved: the sidebar and session header follow the new design; the page now fits one screen and only the content scrolls.
- Improved: approval cards keep just "Allow" and "Deny", with deny-with-reason under "⋯"; waiting for your reply stands out more.
- Improved: Claude Code and Codex sessions started in a terminal earlier move over to the chat view on their own when idle.
- Fixed: the chat view wrongly said "Claude Code exited" while Claude Code updated itself on Windows.
- Fixed: with a long session title, or when opened on a phone, the chat view kept showing "Waiting for your choice" although the terminal wasn't waiting.
- Fixed: with several chat views open, live updates used up the browser's connections and pages stalled; now only the chat you're looking at stays live.
- Fixed: Codex usage sometimes didn't show right after Codex connected or disconnected.
- Fixed: when running as root (for example in WSL or a container), Claude Code terminals without full access exited right away with "cannot be used with root/sudo privileges" (same as stable 1.40.1).
- Fixed: after signing in to or out of a Claude Code account, new conversations asked you to pick a theme and read the security notes again. Both are now skipped (same as stable 1.40.2).
- Fixed: Claude Code opened as a plain terminal with full access still showed the Bypass Permissions warning. It now starts straight away (same as stable 1.40.2).
- Fixed: in Docker, when `~/.claude.json` was mapped as a folder, Claude Code went through first-run setup every time. It now remembers (same as stable 1.40.2).
- Fixed: for a few seconds after Claude Code started, the chat view sometimes showed a pending choice. It now shows that Claude Code is starting until you can type (same as stable 1.40.2).
