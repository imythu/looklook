看看客户端 1.2.0：Codex 对话、可以选择 shell、在客户端里一键更新、报告问题，手机按键更好用。

- 新增：Codex 对话模式。新建会话时选择 Codex，可以直接以对话方式给 Codex 布置任务，查看命令、文件改动和计划，并在网页里回答它的提问或批准操作；也可以照旧以终端方式打开。“我的终端”改名为“我的会话”。
- 新增：新建终端时可以选择 shell。Windows 默认依次使用 PowerShell 7、Windows PowerShell、cmd，也可以选 Git Bash、WSL 或自己填写（例如 bash）；Linux 和 macOS 可以选系统里的 bash、zsh、fish 等。默认 shell 可以在“设置”里修改。
- 新增：自动检查更新。有新版本时菜单和页面顶部会提醒，关掉后同一个版本不再提醒；点“立即更新”即可下载安装并自动重启，终端里正在运行的任务不受影响。也可以在“设置 → 关于”里手动检查。
- 新增：“设置 → 问题与日志”可以查看最近的错误记录，并通过“报告问题”把问题描述和日志发给我们（发送前可以预览，密钥和访问码会自动隐藏）。
- 改进：选择文件夹改为弹窗，Windows 上可以在“此电脑”里切换不同的盘。
- 改进：手机按键条可以收成一行；“更多”里按 Linux、macOS、Windows 常用键和 AI 助手（Claude Code、Codex）分类，本机系统排在最前面。
- 修复：Windows 安装脚本改为 install.bat，双击即可运行，不再弹出“选择打开方式”。
- 修复：Windows 上关闭终端网页后再打开，接不回原来的终端。注意：升级前在 Windows 上创建的后台会话，升级后需要重新启动终端。
