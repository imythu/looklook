看看电脑端 1.49.0：可以直接在飞书里和 Claude Code、Codex 对话了。

- 新增：在飞书里和 AI 对话。给机器人发一句话，选好电脑、文件夹和 Claude Code 或 Codex，就在那台电脑上开一个会话。AI 的回复在卡片里实时出来，需要你批准或选择时，卡片发到同一个话题里。在话题里回复就是接着说，卡片上的「停止」可以打断这一轮。
- 新增：可以发图片和文件给 AI。AI 这一轮写出的文件（图片最大 10MB，其他文件最大 30MB）会发回话题。
- 新增：用卡片上的「新会话」按钮、机器人菜单「新会话」，或发 /new 加一句话，都能开一个新会话。机器人菜单「会话」列出正在跑的会话，可以在飞书里接着聊。菜单「任务」打开任务页。
- 新增：在群里 @ 机器人也能用（要单独打开）。只回应绑定的你，别人 @ 不会理。
- 默认关着，在 设置 → 通知 里打开「在飞书里和 AI 对话」。从飞书开的会话不会用“全部权限”。
- 要用这些功能，请在飞书开放平台给应用加上权限 cardkit:card:write、im:resource、im:message.group_at_msg:readonly，订阅事件 application.bot.menu_v6，并按设置页的说明配好机器人菜单（new、sessions、tasks），然后重新发布应用版本。
