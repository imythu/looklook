Looklook client 1.12.1: fixes remote access reconnecting over and over and the false "Can't reach the Looklook server" warning.

- Fixed: in 1.12.0 the remote connection dropped and reconnected every few seconds, so the top of the page kept saying it couldn't reach the Looklook server (while the top-right showed "Remote online"), and remote sessions could occasionally drop.
- The warning at the top now says what actually went wrong: no network, a Looklook server error (with its code), or remote access working but account status not yet synced.
- If the app quits unexpectedly, it now records where it failed and includes that when you send a problem report, so we can track it down faster.
