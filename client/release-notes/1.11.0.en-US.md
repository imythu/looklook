Looklook client 1.11.0: Claude Code and Codex can use third-party model providers (relays).

- New Settings → Model providers: pick a recommended provider (marked “Ad”) or enter your own endpoint for Claude Code and Codex separately, then add an API key. Terminals created or restarted afterwards use that endpoint. You can switch back to the official API at any time.
- Before first use you need to read and accept a disclaimer: these services are run by third parties, your conversations and code go directly to the provider, and costs or losses are between you and the provider.
- Your API key stays on this computer (readable only by you), is never uploaded, and never appears in any process's command line. With a third-party endpoint, Claude Code runs with ANTHROPIC_API_KEY cleared so your official key is not sent along; Codex leaves your ~/.codex/config.toml and ChatGPT sign-in untouched.
- The new-terminal dialog shows which endpoint the terminal will use, with a link to change it.
