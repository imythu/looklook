看看电脑端 1.17.0：Claude Code 会话新增“对话”界面，可以像聊天一样和 Claude Code 对话、审批操作、发图片，终端里的功能一个不少、随时切换；另外撤下了输入框等几项功能。

- 新建的 Claude Code 会话多了“对话”标签（默认打开）：回复、工具调用、文件改动（diff）、待办清单都整理成卡片显示，手机上也好看。已有的会话在“编辑”里打开“对话界面”，重启会话后生效。
- 在对话里直接发消息和图片（粘贴或选择），输入 / 会提示常用命令，以及你自己和项目里的自定义命令、技能；运行中可以随时停止。
- Claude 要执行命令、改文件时，在对话里点“允许 / 本次会话都允许 / 拒绝”（拒绝时可以告诉 Claude 原因）；Claude 提问时直接点选项回答；写好计划后点按钮批准。终端里也同时可以回答，哪边先答算哪边的。
- Claude 正在写的内容会先灰色显示出来，不用等整段写完；子代理（Agent）可以展开查看它的每一步。
- 选择模型、登录、恢复会话这类需要在终端里操作的界面，会自动切到“终端”标签，操作完自动切回对话。
- 会话列表上会标出“等待确认”“等你回答”“需要终端操作”；页面在后台时，需要你处理或做完了会发浏览器通知。
- 对话界面就是同一个 Claude Code 的另一个视图：关掉网页、客户端重启或更新，任务都继续运行，回来后内容会补齐。
- 撤下终端下方的输入框、“DSH（终端）”会话类型（已有的会自动改成运行 `dsh tui` 的自定义命令会话）、手动设置 AI 工具位置，以及桌面版的“这台电脑 / 所有电脑”切换。
