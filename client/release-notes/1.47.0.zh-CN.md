看看电脑端 1.47.0：DSH 在会话标签里直接打开，Codex 支持 Git 工作树，设备选择和历史记录更顺手。

- 新增：Codex 对话里的 /new 在 Git 仓库中会先问“新对话在哪运行”，可以新建一个独立的 Git 工作树；/worktree 能把当前对话接到新工作树里、在新工作树开新对话，或回到已有工作树里的对话。和 Codex 终端里建的工作树互通。
- 新增：macOS 上 设置 里可以一次授权桌面、文稿、下载等常用文件夹，也能直接打开“完全磁盘访问权限”设置。
- 改进：DSH 会话在会话标签里直接打开它的网页界面，远程访问时也能用；需要时也能在浏览器里打开。
- 改进：历史记录默认先看当前电脑，边滚动边加载，搜索时自动搜对话内容；双击或回车直接接着聊。
- 改进：新建会话时，没装 DSH、Codex、Claude Code 或 OpenCode 会引导你先安装。
- 修复：电脑端输入框有时离窗口底部很远；该聚焦输入框时没有聚焦。
- 修复：手机上“我的”菜单底部被遮住。
- 修复：选好的电脑没记住，经常跳到别的电脑；更新通知看不出是哪台电脑。
- 修复：macOS 自动更新后会再次询问已经授权过的文件访问（从这个版本之后的更新生效）。
