Looklook desktop 1.17.0: Claude Code sessions get a new Chat view — talk to Claude Code, approve actions and send images like in a chat app, with everything in the terminal still there and one tap away. A few older features were removed.

- New Claude Code sessions get a Chat tab (opened by default): replies, tool calls, file changes (diffs) and to-do lists show up as cards, and it works well on phones. For existing sessions, turn on "Chat view" under Edit and restart the session.
- Send messages and images (paste or pick) right in the chat. Typing / suggests common commands plus your own and the project's custom commands and skills. You can stop Claude at any time.
- When Claude wants to run a command or change a file, tap Allow / Allow for this session / Deny in the chat (and tell Claude why if you deny). Answer Claude's questions by tapping an option, and approve its plans with a button. You can still answer in the terminal; whichever answers first wins.
- What Claude is writing shows up in gray right away instead of after the whole passage is done, and sub-agents (Agent) can be expanded to see each step.
- Screens that need the terminal — picking a model, signing in, resuming a session — switch to the Terminal tab automatically and come back to the chat when you're done.
- The session list marks sessions that need approval, have a question or need the terminal, and the browser notifies you when the page is in the background.
- The chat view is just another view of the same Claude Code: closing the page, restarting or updating the client doesn't stop the task, and the conversation catches up when you come back.
- Removed: the input box under the terminal, the "DSH (terminal)" session type (existing ones become custom sessions running `dsh tui`), manually setting AI tool locations, and the desktop app's "this computer / all computers" switch.
