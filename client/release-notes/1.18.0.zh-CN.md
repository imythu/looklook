看看电脑端 1.18.0：Codex 会话也有“对话”界面了，和 Claude Code 用同一套：发消息、看回复和命令、在对话里审批，手机上也好用；另外能自动找到 Claude 桌面版自带的 Claude Code。

- Codex 会话多了“对话”标签（新建时默认打开）：回复、运行的命令和输出、改动的文件（diff）、待办清单都整理成卡片显示，和 Claude Code 的对话界面一样。已有的 Codex 会话升级后会自动打开这个开关，下次启动会话时生效。
- Codex 要运行命令、改文件时，在对话里点“允许 / 拒绝”（拒绝时可以告诉 Codex 原因），也可以选“在终端里回答”；运行中可以随时停止。
- 第一次在某个文件夹里启动 Codex 时，“要信任这个文件夹吗？”直接在对话里确认，不用切到终端。
- 开启对话界面之前就在运行的 Codex，对话标签里会提示“没有接入对话界面”，可以一键重启并接入。
- 对话模式的 Codex 用看看自己的配置（`~/.codex/looklook-chat.config.toml`）带上需要的 hooks，你自己的 Codex 配置不会被改动。
- 第一版暂不支持在 Codex 对话里发图片、“本次会话都允许”和计划确认，这些仍可在终端里操作。没验证过的 Codex 版本会在对话顶部提示。
- 电脑上没有把 `claude` 加到命令路径、只装了 Claude 桌面版时，新建 Claude Code 会话会自动使用桌面版自带的 Claude Code。
