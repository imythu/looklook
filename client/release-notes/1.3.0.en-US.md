Looklook client 1.3.0: Windows and macOS become desktop apps, and Codex chats can run with all permissions.

- New: installers for Windows (setup.exe) and macOS (.dmg), installed like any other app. Looklook now shows the console in its own window instead of opening your browser; closing the window keeps it running in the background, and the tray (menu-bar) icon opens it again.
- The Windows version is in beta: you can use it, but it hasn't been fully tested yet. Please report problems under Settings → Problems & logs.
- New: Codex chats can be opened with "all permissions" — no approval prompts and no sandbox.
- Improved: after creating a terminal, Looklook asks how to open it — in a small window on the current page or in a new tab — instead of navigating away.
- Fixed: "Unable to start Codex: No such file or directory" when Codex is installed but Looklook was started from a desktop icon or the tray.
- Fixed: an extra "exec" icon in the macOS Dock.
- Improved: dropped remote connections are noticed and reconnected sooner.
