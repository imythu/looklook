LookLook desktop 1.44.1: quieter notifications, a safety net, and a smoother Codex chat.

- New: quiet hours for notifications (in each computer's local time). Nothing is sent during them, and you get one summary when they end. “Done” notifications can be batched into one card every 10/30/60 minutes; errors and requests that need you are still sent right away.
- New: a single reminder when the AI has been working for a long time without progress, with a Stop button in Feishu. Come back after 30 minutes or more and the board shows what finished, failed or is waiting for you while you were away.
- New: a safety net. Commands that are hard to undo, such as force-pushing, hard resets, deleting your home folder or dropping a database, need your confirmation first, even in full-permission mode. You can add your own deny rules too, under Settings → AI → Safety net.
- New: a checkpoint of the working folder at the start of every turn, including uncommitted changes. In the terminal's Git tab you can see what changed since then and go back to before that turn.
- New: check 5-hour and weekly usage for third-party APIs such as Zhipu GLM, Kimi and MiniMax. When a local Ollama is found, set it up as Claude Code's API in one click.
- New: the Local pages page lists ports listening on this computer, recognizes OpenClaw, Hermes and common dev servers, and turns one into a page you can open from anywhere in one click.
- New: install keys. When installing LookLook on a cloud server, in a startup script or in Docker, sign in with a key generated on the Computers page instead of scanning a code.
- Improved: the Codex chat now handles the prompts Codex shows when it starts in the terminal. New folders no longer get stuck on “Trust this folder?”, hooks that need review are listed in the chat to trust or skip, you're told to sign in from the terminal when needed, and archived conversations can be continued directly.
- Improved: the Codex chat tells you when a new Codex version is out. If Codex was installed with npm you can update in one click, and the chat switches to the new version once it's idle. Codex in the terminal no longer gets stuck on its own update prompt.
- Fixed: links in replies that point to files on your computer didn't open, and local screenshots in replies showed only an empty box.
- Fixed: on a phone, Claude Code questions with long option descriptions couldn't be answered and showed “the interface has changed”.
