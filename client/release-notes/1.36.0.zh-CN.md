看看电脑端 1.36.0：Claude Code 可以在多个账号和第三方接口之间切换，新建会话时也能另选；Claude 在工作时也能接着发消息。

- Claude Code 账号（设置 → AI 助手）：除了本机默认账号，还可以添加别的官方账号和第三方接口（兼容 Anthropic 官方格式的接口，用你自己的 API Key）。选一个作为默认，之后新建的会话就用它；开始页可以给这一个会话另选。已经开着的会话不受影响，重启后也还用新建时选的那个。
- 添加官方账号后直接在弹窗里登录：打开或复制授权页地址，在浏览器里登录后把授权码贴回来。登录由 Claude Code 自己完成，看看不读取、不保存你的登录凭据。几个官方账号共用设置、CLAUDE.md、技能、插件和对话记录，只有登录状态各自独立。
- 第三方接口可以指定模型（默认模型和 Opus / Sonnet / Haiku 各自对应的模型）。以前在“模型服务商”里给 Claude Code 选的接口会自动变成一个第三方接口并设为默认；“模型服务商”以后只管 Codex。
- 对话页里，Claude 在工作时也能发消息：回车排队，这一步做完后 Claude 会读到；Ctrl+回车（手机上点“立即发送”）让它马上读到，正在跑的命令转到后台。
- Claude Code 额度用完时，菜单换成中文（附原文），显示重置的具体时间和还剩多久；60 秒没人选时自动选“重置后自动继续”，关着页面也有效。
- 用量页的 5 小时 / 7 天额度显示具体的重置时间和时区；用量改为只读 Claude Code 自己缓存的数字，界面会注明是多久前取得的。
- 没开全部权限的 Claude Code 会话也能在对话界面切到“全部权限”（已经开着的会话重启后生效）。
- 以前在终端里开的 Claude Code / Codex 会在空闲时自动接着同一段对话转到对话模式，不打断正在做的事。
