Looklook desktop 1.36.0: switch Claude Code between several accounts and third-party endpoints, and pick one per session. You can also keep sending messages while Claude works.

- Claude Code accounts (Settings → AI assistants): besides this computer's account, add more official accounts and third-party endpoints (endpoints compatible with Anthropic's API format, using your own API key). Pick one as the default and new sessions use it; on the start page you can pick another one for a single session. Open sessions don't change, and each session keeps the account it was created with, even after a restart.
- Sign in to an added official account right in a dialog: open or copy the authorization page address, sign in in your browser, then paste the code back. Claude Code does the sign-in itself; Looklook never reads or stores your login credentials. Official accounts share settings, CLAUDE.md, skills, plugins and conversation history; only the logins are separate.
- Third-party endpoints can set models (the default model and the ones used for Opus, Sonnet and Haiku). The endpoint you chose for Claude Code under "Model providers" becomes a third-party endpoint and the default; "Model providers" now covers Codex only.
- In the chat view you can send messages while Claude works: Enter queues the message and Claude reads it after the current step; Ctrl+Enter (or "Send now" on phones) makes Claude read it right away and moves running commands to the background.
- When Claude Code runs out of usage, its menu is shown in Chinese with the original text, along with the exact reset time and how long is left. If nobody picks an option within 60 seconds, "wait and continue automatically" is chosen for you, even with the page closed.
- The 5-hour and 7-day limits on the usage page show the exact reset time and time zone. Usage now comes only from Claude Code's own cache, and the page says how long ago it was fetched.
- Claude Code sessions started without full access can switch to full access from the chat view (sessions already open need a restart).
- Claude Code and Codex sessions you started in a terminal earlier move to the chat view automatically, continuing the same conversation once they are idle, without interrupting work in progress.
- Fixes: unsent text in the input box was lost after a disconnect or when the page was reloaded; commands moved to the background mid-run were missing from Tasks; suggested replies sometimes popped up and vanished; the update prompt came back after being closed; the chat view could scroll sideways on phones; on Windows the chat view showed "exited" after Claude Code updated itself.
- Status-line verbs have been retranslated, with the original word shown after the Chinese.
