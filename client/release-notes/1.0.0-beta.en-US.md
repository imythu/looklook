First beta of the Looklook client.

- Sign in with your Looklook account, then open this computer's terminals from your phone or any browser at your personal address. Closing the page doesn't stop what's running in them.
- Unlimited terminals: a plain shell, Codex, Claude Code or your own command. Codex and Claude Code can be installed with one click if missing.
- Built-in remote access tunnel: no public IP or extra setup needed.
- Local web pages: expose development pages on this computer (such as localhost:5173) under your personal address, up to 10.
- Bundled terminal fonts (JetBrains Mono and LXGW WenKai Mono) with light and dark themes; on phones, a key bar with Esc, Tab, arrow keys and Ctrl combinations.
- Runs on Linux (x86_64 / ARM64), macOS (Apple silicon) and Windows (x86_64). On Windows the program exits when you close the terminal page.
- Installers are not code-signed yet: on Windows and macOS you need to allow the app on first launch; see the Download page for steps.
