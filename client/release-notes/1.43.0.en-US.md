LookLook desktop 1.43.0: a new layout with an icon rail and a full-height session list, machine filters that scale, easy copy, find and export in chats, and a Codex chat view that looks like Codex.

- New layout: a slim icon rail on the left (new session, sessions, tasks, past conversations, tools, settings, connection, avatar) with the session list taking the whole column next to it. Drag its edge to resize; it tucks away on tool pages. On phones, a bottom tab bar: Sessions · Tasks · New · Tools · Me.
- The machine filter is now a dropdown: pick several, search, switch to "only this one" in one tap, or show online machines only; each row shows the OS, status and session count. A status filter (needs you / running / stopped) sits next to it, and grouping (by project / machine / recent) moved into the list's ⋯ menu.
- New Ctrl+K (⌘K on Mac) quick switcher for sessions, projects, past conversations and common actions. Ctrl+/ lists every shortcut.
- Copy in chats: every code block has a copy button; your own messages can be copied or put back in the input box to edit and resend; commands and their output can be copied; on phones, long-press a message for Copy all / Select text / Edit in input box.
- Ctrl+F finds text in the conversation and highlights every match; Alt+↑ / Alt+↓ jumps between your messages; the side panel's new Outline tab lists everything you sent and can copy the chat as Markdown or download it as .md.
- The Codex chat view now has its own monochrome, sans-serif look: gray bubbles, a gray tool timeline, a round black send button and a softly breathing Codex mark while it works.
- Fixed: typing /new in Claude Code now returns to the empty chat and focuses the input box.
- Fixed: the ⋯ menu on sidebar projects did nothing when clicked.
- Fixed: on macOS the Codex chat said it couldn't reach Codex, or that Codex wasn't installed, because apps started from the Dock don't get your shell's PATH. If it still fails, the message now says why.
- Improved: on Windows, a new Codex session shows "starting" instead of briefly flashing a connection error.
