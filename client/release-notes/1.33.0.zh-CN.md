看看电脑端 1.33.0：设置、电脑、账号和会员改成从右侧滑出的抽屉，不用离开正在用的会话；电脑断线时终端还能看，连回来自动接上；创建会话更顺手；macOS 升级后不再反复询问文件夹权限。

- 设置、电脑、账号、会员从右侧滑出，背后的会话和终端保持连接；按 Esc、点空白处或浏览器的返回都能关掉，关掉后回到会话的输入框。手机上占满全屏，返回手势关闭。
- 电脑断线时，它的终端 tab 不会消失，内容照常能看，并提示暂时不能输入；电脑连回来后终端马上自动重连。
- “立即更新”不再挡住整个页面：可以关掉对话框在后台更新，顶部横幅显示进度；重启太久时可以直接刷新页面。
- 创建会话：选了“全部权限”就不用再单独确认 root；工具类型只显示最常用的几个，其余在“更多”里；工具还没安装时，点开始会先自动安装（可选 npm 镜像），装好后接着开始。开始不了时按钮旁会说明原因。
- 对话界面：工具调用的参数逐项列出，JSON 自动排版并可复制，链接可以点；内容太长被截断时可以加载完整参数。
- Claude Code 跑完一轮后终端输入框里给出的建议回复，对话界面里也会显示，点一下或按 Tab 填入。
- 账号菜单里可以一键复制你的专属远程地址，“远程访问”卡片收起时也显示地址。
- macOS：从这个版本起每个版本都用同一个签名，以后升级不会再询问是否允许访问文稿、桌面等文件夹（升级到 1.33.0 时还会再问最后一次）。
- Linux：自动更新把程序放进数据目录，在 Docker 里运行时只需要映射数据目录一个目录，就能保留自动更新。
