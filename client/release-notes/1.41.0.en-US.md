LookLook desktop 1.41.0: new sessions start as a draft, chats have input history and an inline /resume picker, and the Codex chat view now works as well as Claude Code's.

- New: new sessions start as a draft. Pick the project, type and account, write your first message, then start; the session opens right away and sends your first message once the conversation is up, with a retry if it doesn't start. Drafts are kept per project, so switching projects doesn't lose your text. Terminals and custom commands open with one click.
- New: folders of the same git repository on several computers are merged into one project, and the project page lets you switch computers; offline computers show when they were last seen.
- New: input history. Press Up/Down in the input box to go through what you sent before, or use the history button or Ctrl+R to search. For Claude Code it's the same history as pressing Up in the terminal.
- New: type /resume in a chat to pick an earlier conversation in this project right above the input box and continue it, without leaving the page.
- New: Codex chats show sub-agents, and you can open one to see each of its steps; they also show web searches, the command being run, context compaction and reconnect progress.
- Improved: in Codex chats, images you send are shown; messages you add while Codex is answering are marked as added mid-turn and no longer appear both in the queue and in the conversation.
- Improved: on computers, the session bar no longer repeats the session name already shown in the tab.
- Fixed: after running for a while, opening terminals from phones or the web over a direct connection failed more and more often (ports ran out).
- Fixed: after adding a message in a Codex chat, the answer preview joined the two answers together.
- Fixed: the background Codex process sometimes kept running after a Codex chat ended (Codex installed with npm).
- Fixed: the chat waiting card sometimes showed a raw text code; on phones "Running command" was squeezed to "Running…".
