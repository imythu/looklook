Looklook desktop 1.35.0: a redesigned chat view. Tool calls fold into a timeline, and you can tell at a glance when Claude is working or waiting for you. Replies are easier to read and can be copied in one click. From this version on, the client is open source under AGPL-3.0.

- Tool calls between two replies fold into one card, such as "Ran 2 commands · Read 2 files · 1 edit +23 −0". Open it to see a timeline: green dots succeeded, red dots failed, and the running step pulses. Subagents, to-dos, questions and plans still show on their own.
- Command cards are titled with Claude's own description (for example "Run the tests"), with the command on the next line and the number of output lines. Reading a file shows only what was read.
- While Claude works, the end of the chat shows what it's doing and for how long, and a light runs around the input box. When Claude needs your approval, the card's border pulses.
- Diffs have line numbers, and the added/removed counts come with a small ratio bar. Collapsed thinking shows its first sentence.
- A subagent's steps show as soon as you open its card. Long runs show the latest 25 steps first; earlier ones are one click away.
- Reply text is larger and easier to read. Each reply ends with a button to copy the whole reply and how long the turn took.
- The status line above the input box is gone. A note appears there only when reconnecting, on errors, or when Claude is waiting for you. The side panel button moved to the top right of the chat, and running background tasks show in the input box.
- The suggested reply appears as grey text in the input box; press Tab to use it. On phones, tap it.
- A new chat offers a few ways to start (explain the project, review changes, run the tests); click one to put it in the input box.
- The context ring shows a percentage, file names in tables no longer break in the middle, and tool cards are more compact on phones and narrow windows.
- If your system is set to reduce motion, the chat view's animations stop.
