看看客户端 1.5.0：一个账户最多 7 台电脑，终端里可以直接传文件、贴图片给 AI。

- 同一个账户最多可以同时登录 7 台电脑。远程打开时，所有电脑的终端按电脑分组显示在同一个页面里；本机网页、设置等页面在顶部切换电脑。
- 不同电脑可以把同一个本机端口分别添加为本机网页。
- 已经登录 7 台时，新电脑会被拒绝并列出已登录的电脑；在网页“我的电脑”里退出一台后即可登录。同一台电脑重新登录不占新名额。
- 终端标题栏新增“文件”按钮：把文件上传到终端当前所在的目录，手机上也能从相册选图。大文件分段上传，网络中断后自动接着传。
- 电脑上可以把文件拖到终端里，或直接 Ctrl+V 粘贴截图、复制的文件。
- 在 Codex、Claude Code 里粘贴或上传图片，会直接作为图片发给 AI；这些图片放在看看自己的临时目录，7 天后自动清理，不会混进项目。
- 终端里运行 rz 会自动弹出上传面板，运行 sz 会给出下载；同时自带 trz / tsz（trzsz），经 SSH 到其他机器时也能传文件。
- 自动更新：没有打开的终端 10 分钟后自动安装新版本（可在设置里关闭）；没有屏幕的机器可以用 `looklook update`。
- 新增“系统”页：CPU、内存、磁盘、网络与占用最多的进程。
- Codex、Claude Code 可以通过本机 MCP 自动添加和复用本机网页（在“本机网页”页一键安装，默认关闭）。
- 远程访问更快：浏览器直接连到中转服务器，不再绕经看看平台。
- Codex 统一以终端方式打开，去掉了之前的对话模式。
- 这个版本与旧版客户端的远程访问方式不兼容，请升级；升级前旧版客户端无法被远程打开。
