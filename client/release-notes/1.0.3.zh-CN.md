看看客户端 1.0.3：第一个稳定版，手机上操作终端更顺手。

- 手机和平板上的终端底部新增按键条：Esc、Tab、Ctrl、Alt、Shift、方向键、Home/End、Ctrl+C 和粘贴常驻；“更多”里有常用快捷键（每个都附说明，如“中断”“清屏”“搜历史”）、手机键盘不好打的符号（| ~ / \ { } 等）、翻页键和 F1–F12。
- Ctrl / Alt / Shift 点一下只作用于下一个键，再点一下锁定，第三下取消；对手机自带键盘打的字同样生效，比如点 Ctrl 再打 r 就是 Ctrl+R。
- 方向键、删除、翻页键按住可以连发；点按键条不会弹出或收起手机键盘；横屏时按键条自动压成一行，给终端留出更多空间。
- 按键条只在手机和平板上出现，电脑上不显示。终端顶部的键盘按钮可以随时隐藏或显示它。
- 包含 1.0.x 测试版的全部改进：远程通道连接状态和失败原因说明、终端连接与自动重连提示、可拖动的悬浮终端窗口、托盘菜单按服务状态置灰、完整的英文界面等。
