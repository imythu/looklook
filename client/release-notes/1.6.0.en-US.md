Looklook client 1.6.0: QR sign-in on servers, choose your own remote route, and OpenCode and DSH support.

- New: on a server without a desktop, run looklook login and scan the QR code shown in the terminal with your phone to approve. Ctrl+C cancels. If you're already signed in, it shows the account instead.
- Command-line help and messages are now bilingual (Chinese and English), and looklook upgrade works as an alias for looklook update.
- New "Remote route" on the Account page: routes are still picked automatically, but if remote access feels slow you can test latency and pick a faster route. The choice is remembered and applies at once.
- New OpenCode terminal type: start it in one tap (optionally with full access), install it in one click if it's missing, and connect it to Looklook's MCP.
- New DSH (DeepSeek Harness): one per computer, using its own web UI, opened as a local page at the same address locally and remotely. OpenCode and DSH support is new; please report problems under Settings → Problems & logs.
- Phone keyboard: the on-screen keyboard no longer pops up when a terminal opens. Tap the terminal or the ⌨ key to bring it up. On small screens the key bar shrinks to one row, the header hides in landscape, Enter is always on the bar, and keys scale with the screen.
- The terminal's Upload button is easier to find, with a one-time tip. Files sent to Codex and Claude Code are pasted the way each expects (images as [Image #N], other files as paths).
