A beta of Looklook desktop that includes everything in stable 1.44.0, plus a status bar and several usage and session improvements. You can opt in to beta versions in Settings.

- New: "Settings → Updates → Get beta versions", off by default. When on, you get both stable and beta releases and install whichever is newer. Turning it off won't roll back; you'll move to the stable release once its version passes the beta you're on.
- New: a status bar at the bottom on desktop shows the connection, how many sessions are running or waiting for you, and how much of each account's 5-hour limit is left (click for refill times and which one to use). It follows the current tab's colors.
- New: the new-session type menu has separate "Codex chat" and "Codex terminal" entries, each showing how much of the limit is left, with a warning when the one you picked is almost out.
- New: a small ring next to the input shows how much of your 5-hour limit is left; on phones, tapping it opens a usage panel from the bottom.
- New: commit selected files right from the Git tab, optionally pushing afterwards. Files changed in this conversation are listed first.
- Improved: on desktop the page fits one screen; the icon bar, session list and content scroll on their own, with no page-wide scrollbar on the right.
- Improved: approval cards keep just "Allow" and "Deny", with deny-with-reason under "⋯"; waiting for your reply stands out more.
- Fixed: with several chat views open, live updates used up the browser's connections and pages stalled; now only the chat you're looking at stays live.
- Fixed: Codex usage disappeared when reaching OpenAI timed out; it now keeps the last reading and shows how old it is.
- Fixed: the Claude Code chat view sometimes kept showing a message as queued long after it had been sent.
