看看电脑端 1.41.0：新会话先写草稿再开始，对话里能翻输入历史、/resume 直接选以前的对话，Codex 对话界面跟 Claude Code 一样好用。

- 新功能：新会话先是草稿。选好项目、类型、账号，写好第一句再开始；会话马上打开，对话起来后自动发出第一句，没起来可以重试。草稿按项目存着，换项目不丢字。终端和自定义命令点了就开。
- 新功能：同一个 git 仓库在几台电脑上的文件夹合并成一个项目，项目页里可以切换电脑；离线的电脑显示上次在线的时间。
- 新功能：输入历史。输入框里按上下键翻以前发过的话，点历史按钮或按 Ctrl+R 搜索。Claude Code 和终端里按上键翻的是同一份。
- 新功能：对话里输入 /resume，在输入框上方直接选这个项目以前的对话接着聊，不用再跳到别的页面。
- 新功能：Codex 对话里能看到子代理，点开看它做的每一步；也能看到网页搜索、正在跑的命令、上下文压缩和重连进度。
- 改进：Codex 对话里，你发的图片会显示出来；回答途中补充的话标成“中途补充”，不再同时出现在“排队中”和对话里。
- 改进：电脑上顶部标签已经写着会话名字，会话栏里不再重复。
- 修复：用了一段时间后，手机或网页通过直连打开终端越来越容易连不上（端口被占满）。
- 修复：Codex 对话里补充一句后，回答预览会把前后两段拼在一起。
- 修复：Codex 对话结束后，后台的 Codex 进程有时没有退出（用 npm 装的 Codex）。
- 修复：对话的等待卡片偶尔显示一串英文代码；手机上“正在运行命令”被挤成“正在运…”。
