LookLook desktop 1.40.2: Claude Code no longer asks you to pick a theme, read the security notes or accept the full-access warning when it starts, and the chat view no longer reports a pending choice while it's still starting.

- Fixed: after signing in to or out of a Claude Code account, new conversations asked you to pick a theme and read the security notes again. Both are now skipped. A theme you chose yourself is kept.
- Fixed: Claude Code opened as a plain terminal (without the chat view) with full access still showed the Bypass Permissions warning. It now starts straight away, like the chat view.
- Fixed: in Docker, when `~/.claude.json` was mapped as a folder, Claude Code went through the first-run setup and asked to trust the folder every time it started. It now remembers.
- Fixed: for a few seconds after Claude Code started, the chat view sometimes showed "Claude Code is waiting for your choice". It now shows that Claude Code is starting until you can type.
