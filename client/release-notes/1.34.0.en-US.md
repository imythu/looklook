Looklook desktop 1.34.0: reconnect a Codex terminal with one click; usage reset times read in days, hours and minutes; Codex shows context usage as soon as you open it.

- A Codex chat's terminal tab has a new "Reconnect terminal" button (under "More" on phones and narrow screens): if the terminal disconnected, you quit Codex, or it's running the local version, one click brings it back to the same conversation the chat is using. Anything still running in the terminal exits first.
- The terminal tab opens Codex automatically only the first time; after that it no longer reopens by itself. Use the button above to reconnect.
- Usage reset times now read like "Resets in 4 h 43 min" and "Resets in 6 d 23 h" instead of 4h02m or 162h42m.
- When you open a Codex chat (or after the desktop app restarts), the context usage ring next to the input box and the Usage panel show right away, without sending a message first.
