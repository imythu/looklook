看看电脑端 1.28.0：打开的会话排在顶部标签里，会话名跟着 AI 走，可以在 Docker 容器里开会话，以前的对话能按多种条件筛选。

- 打开的会话在顶部排成标签，按打开的先后排，可以拖动调整。点 ×、鼠标中键或右键菜单（关闭其他 / 右侧 / 全部）关掉标签，终端照常运行。标签多了点右边的 ▾ 看全部，可以搜、可以一个个关。
- 左侧会话不再乱跳：运行中的排前面，再按启动时间从新到旧，有输出也不换位置。
- 会话名以 AI 自己的会话名为主（Claude Code、Codex、OpenCode 的对话标题或它设置的终端标题），你自己起的名字显示在旁边。
- 会话顶栏的电脑和目录缩成一行小字，不再占地方。
- 新建会话时可以选 Docker 容器：从运行中的容器里搜索选择，填容器里的目录；容器里是 root 并开了全部权限时自动加上 IS_SANDBOX=1。容器里的会话暂时只有终端，没有对话界面。
- 以前的对话页重新设计：左边按工具、电脑、项目、分支、状态、时间、收藏筛选，每项带数量；按时间、项目或电脑分组；点一条在右边看完整对话；可以收藏和隐藏；搜索框回车会在对话全文里搜，也支持 agent:codex、branch:main 这样的写法。
- 电脑上点会话或标签后，光标直接落在终端或对话输入框里；手机上不再自动弹出输入法。
- 修复 macOS App 里左侧会话要点两下或用力按才能切换的问题；App 在后台时点一下也能直接切换。
- 终端里去掉了选中文字后出现的“复制”小按钮（用 ⌘C / Ctrl+Shift+C 复制）。链接按住 ⌘ / Ctrl 点击直接打开，普通点击弹出“打开 / 复制链接”。
- 手机上可以下拉刷新页面；终端连不上或正在连接时也能下拉刷新。
- 连接更简单：去掉了“同一局域网直接打开”，App 里本机直接打开、其他电脑走 WebRTC，在同一局域网里会优先用局域网地址（跳过 Clash TUN 等虚拟网卡）。电脑菜单里每台电脑旁显示连接方式和延迟（局域网直连 / 公网直连 / 中转）。
- 网页上可以设置“只看这台电脑”。
- Linux 首次安装默认开启局域网访问（方便无界面的服务器和 NAS，可用 `looklook access lan off` 关闭）；新增 `looklook restart`，`looklook status` 显示远程访问、局域网和白名单。
