看看电脑端新界面的 Beta 版，已包含正式版 1.40.1 的修复。界面整体改版，加了底部状态栏和命令面板，还可以在设置里选择接收 Beta 版。

- 新增：「设置 → 更新 → 接收 Beta 版」。打开后正式版和 Beta 版都会收到，安装版本号较新的一个；关闭后不会退回旧版本，待正式版的版本号超过当前 Beta 版时再更新到正式版。
- 新增：底部状态栏，显示有几个会话在运行、几个在等你回复，以及各账号还剩多少额度，颜色跟着当前标签走；按 Ctrl+K 打开命令面板，快速跳到会话、页面和常用操作。
- 新增：新建会话改成「用什么开始」列表，Codex 分成「Codex 对话」和「Codex 终端」两种，各家工具用不同颜色区分。
- 新增：输入框旁的小圆环显示账号 5 小时额度还剩多少，点开可以看 5 小时和每周的额度。手机上点圆环会从底部弹出额度面板；新建会话时每种工具后面写着还剩多少；打开菜单，底部列出各账号的额度。
- 新增：Git 标签里可以勾选文件直接提交，可选提交后推送；本次对话改过的文件单独列在前面。
- 改进：侧栏和会话顶栏按新设计调整；整个页面固定一屏，只有内容区域滚动。
- 改进：审批卡片只留「允许」「拒绝」两个按钮，带理由拒绝等放进「⋯」菜单；等待回复时更醒目。
- 改进：以前在终端里开的 Claude Code、Codex 会话，空闲时会自然转到对话界面继续使用。
- 修复：Claude Code 在 Windows 上自动更新时，对话页误报「Claude Code 已退出」。
- 修复：会话标题较长或在手机上打开时，对话页一直显示「等你选择」，实际终端并没有在等。
- 修复：同时打开多个对话页时，实时推送占满浏览器连接导致页面卡住；现在只有正在看的对话页保持实时连接。
- 修复：Codex 刚连上或断开时，用量偶尔显示不出来。
- 修复：以 root 用户运行（例如 WSL、容器里）时，没开全部权限的 Claude Code 终端一启动就报 “cannot be used with root/sudo privileges” 并退出（同正式版 1.40.1）。
