Looklook desktop 1.24.0: a redesigned chat view for Claude Code (beta).

- The chat page no longer pops up the terminal. Claude Code's pickers, such as the model-switch confirmation, show up as dialogs in the chat page.
- The model menu lists the models your account can actually use, and the check mark follows the model that answered last. Each model has its own effort levels.
- Approvals, questions and plan reviews all happen in the conversation. If a plan isn't right, tell Claude what to change and it rewrites the plan.
- A new composer with permission mode (Shift+Tab), model and effort, and a context ring. Type / for the command menu.
- A side panel shows changes, subagents and background commands, usage and limits, and permission rules and MCP servers.
- The chat view is still in beta. Switch to the Terminal tab at any time for the full Claude Code.
