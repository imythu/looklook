看看电脑端 1.42.0：新增“任务”页，所有电脑上的 Claude Code / Codex 会话一眼看清谁在等你。

- 新增：“任务”页把会话分成“等你处理 / 正在干活 / 刚结束”三组，每行一句话说清现状（要跑的命令、问你的问题、正在改的文件、这一轮的结果）。
- 新增：在“任务”页直接允许或拒绝、回答选项、处理选择框、停止会话；删目录、强推这类高风险命令会标出来，允许前再确认一次。
- 新增：侧栏和手机顶栏显示“等你处理”的个数，浏览器标签页标题前也会带上个数。
- 改进：没人打开的 Claude Code 会话也会在后台核对状态，看板不会停在过时的“运行中”；额度用完时没人在看，也会自动选“等重置后继续”。
