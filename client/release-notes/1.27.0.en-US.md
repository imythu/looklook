Looklook desktop 1.27.0: Codex sessions get the chat view too, and Codex starts properly on Windows.

- Codex sessions get a "Chat" tab: replies, commands and their output, and changed files are shown as cards, just like the Claude Code chat view. Existing Codex sessions have it turned on after the update; it takes effect the next time the session starts.
- When Codex wants to run a command or change files, tap "Allow / Deny" in the chat; trusting a folder and Codex's own choice boxes are answered in the chat too, without switching to the terminal.
- A Codex that was already running before the chat view was turned on shows "not connected to the chat view", with a one-click restart to connect it.
- Codex in chat mode gets its hooks from Looklook's own profile (`~/.codex/looklook-chat.config.toml`); your own Codex config is not changed. Sending images and picking the model or permission mode aren't in the Codex chat yet; use the terminal for these.
- Fixed Codex terminals on Windows failing with "cannot load codex.ps1" (PowerShell blocks scripts by default; Looklook now starts codex.exe directly).
- Fixed tool cards showing up more than once in the chat, and one of several parallel tool calls spinning forever.
- If only Claude Desktop is installed, new Claude Code sessions use the Claude Code that comes with it.
