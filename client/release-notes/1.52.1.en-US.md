LookLook desktop 1.52.1: DSH opens even when its port is taken, ⌘W / Ctrl+W closes the current tab, and Duplicate session starts a fresh session again.

- Fixed: When another program was using DSH's port, DSH couldn't start and the page stayed on "Getting the startup token". It now notices that DSH has exited, restarts it on a free port, and the diagnostics name the program holding the port.
- New: ⌘W (Mac) / Ctrl+W closes the current session tab. With focus in a terminal, Ctrl+W still deletes a word there; in the Mac desktop app ⌘W closes the tab from a terminal too, and Close Window moves to ⇧⌘W.
- Improved: "Duplicate session" again opens a fresh session with the same settings. To continue the existing conversation in a new direction, use the new "Continue in a copy" (only on Claude Code / Codex sessions that have a conversation). The 1.52.0 note saying duplicating copies the conversation no longer applies.
