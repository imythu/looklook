Looklook client 1.16.0: move conversations between Codex, Claude Code and DSH, a new conversation history and chat view, temporary sharing of local pages with a named account, and a fix for terminals that kept reconnecting on Windows.

- Move conversations: on the Terminals page, click "Move conversation" to move a Codex conversation to DSH or back, then keep going in the other tool. The original conversation is never changed. Claude Code conversations can be moved in and out too.
- Conversation history: a new read-only page to search past Codex, Claude Code and DSH conversations, continue one in a terminal, or move it to another tool.
- Chat view: AI terminals switch between Terminal, Chat and Changes. The chat view lists what the AI did in plain words with a risk level, and approval prompts on screen become buttons. The session list shows "needs your OK / working / idle", and the page title counts the ones waiting for you.
- Composer: write a prompt in a normal text box (input methods and voice input work) and send it to the terminal in one go, optionally pressing Enter. Each terminal keeps its own draft.
- New "DSH (terminal)" session type. Claude Code bundled with the Claude desktop app and DSH's install folder are found automatically, or you can set the program location yourself.
- Share a local page with another Looklook account for 1 hour to 7 days, after a security warning. See and revoke active shares at any time.
- The workspace sidebar groups terminals by project folder, with one-click new terminal or AI session per project. Terminals have a new "Duplicate terminal" menu item.
- Desktop app: a "This computer / All computers" switch opens your personal address in the same window.
- Fixed terminals on Windows crashing as soon as they opened (and the page reconnecting forever) when the working folder was deep or had non-English characters, or the install path was long.
- Fixed resumed Codex conversations exiting with "Cannot use the shared background server".
- When a terminal can't connect for a moment, the page says so instead of the browser asking you to sign in.
- The conversation history page now lays out properly on phones.
