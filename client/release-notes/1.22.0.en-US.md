looklook desktop 1.22.0: a tidier Settings page, and it is easier to see which computer you are working on when you have several.

- Settings is now split into sections (General, Terminal, AI models, Network & access, About), shown one at a time instead of one long page.
- Terminal font, colors, default folder, computer name and similar options save automatically; there is no Save button any more.
- With several computers signed in, the sidebar shows which computer the tools apply to and lets you switch right there; the settings page also names the computer you are editing.
- On phones with several computers, the top bar no longer overflows the screen.
