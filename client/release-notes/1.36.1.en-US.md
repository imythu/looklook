Looklook desktop 1.36.1 fixes several chat issues.

- Fixed: after "Send now", a message that had already been delivered stayed in the "Queued" box.
- Fixed: after scrolling up in the terminal, sending from the chat page could hang with "tmux timeout" or "not in a mode" (also when switching terminals), and sent text was sometimes duplicated.
- Fixed: the Claude Code 5-hour and 7-day limits were missing from the usage page. When the numbers are stale, Looklook now asks Claude Code to refresh them itself (this uses no quota); Looklook still never reads your sign-in credentials.
- Fixed: the bottom half of the "working…" line looked blurry.
