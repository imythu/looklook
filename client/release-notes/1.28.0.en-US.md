Looklook desktop 1.28.0: open sessions live in tabs on top, sessions are named after what the AI calls them, sessions can run in Docker containers, and earlier conversations can be filtered many ways.

- Open sessions sit in a tab bar on top, in the order you opened them, and you can drag them around. Close a tab with ×, the middle mouse button, or the right-click menu (close others / to the right / all); the terminal keeps running. With many tabs, ▾ on the right lists them all with search and a close button on each.
- The sidebar no longer jumps around: running sessions come first, then newest start time first, and output doesn't move them.
- Sessions show the AI's own name for the session (the Claude Code, Codex or OpenCode conversation title, or the terminal title it sets); a name you typed is shown next to it.
- The computer and folder in the session bar are now one small line.
- New sessions can run inside a Docker container: search and pick a running container and set the folder inside it. IS_SANDBOX=1 is added when the container runs as root with full access. Container sessions are terminal-only for now, with no chat view.
- The earlier-conversations page is redesigned: filter by tool, computer, project, branch, status, time and stars, each with counts; group by time, project or computer; click one to read the whole conversation on the right; star or hide conversations; press Enter in the search box to search full conversations, and use agent:codex or branch:main.
- On a computer, clicking a session or tab puts the cursor in its terminal or chat box. Phones no longer pop up the keyboard on their own.
- Fixed sidebar sessions in the macOS App needing a double tap or a hard press to switch. A click also works while the App is in the background.
- The terminal no longer shows a "Copy" chip after selecting text (use ⌘C / Ctrl+Shift+C). Links open with ⌘/Ctrl+click; a plain click shows Open / Copy link.
- Pull to refresh works on phones, including on the terminal page while it can't connect.
- Simpler connections: "open directly on the same LAN" is gone. In the App, this computer opens directly and other computers use WebRTC, which now prefers LAN addresses (skipping Clash TUN and other virtual adapters). The computer menu shows each computer's connection type and latency (LAN / direct / relayed).
- The web page has a "Show only this computer" option.
- Fresh Linux installs turn on LAN access by default (handy for headless servers and NAS; turn it off with `looklook access lan off`). New `looklook restart`; `looklook status` shows remote access, LAN and the allow list.
