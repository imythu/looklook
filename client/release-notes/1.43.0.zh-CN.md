看看电脑端 1.43.0：管理台换成“图标栏 + 会话栏”，电脑多了也好筛；对话里能方便地复制、查找、导出；Codex 的对话页有了自己的样子。

- 新界面：最左边一条窄图标栏（新会话、会话、任务、以前的对话、各个工具、设置、连接状态、头像），旁边整栏都是会话列表；会话栏可以拖动改宽度，去工具页时自动收起。手机上底部是“会话 · 任务 · 新建 · 工具 · 我的”标签栏。
- 电脑筛选改成下拉：可以多选、搜索电脑、“只看它”一步切换、只看在线的，每台写着系统、在线状态和会话数；另有状态筛选（等你处理 / 正在运行 / 停了的）。分组方式（按项目 / 按电脑 / 按时间）放进会话栏的 ⋯ 菜单。
- 新增 Ctrl+K（Mac 上 ⌘K）快速切换：搜会话、项目、以前的对话和常用操作，回车打开；Ctrl+/ 查看全部快捷键。
- 对话里的复制：代码块右上角有复制按钮；你发的消息可以复制或填回输入框改一改再发；命令和输出都能复制；手机上长按一条消息弹出“复制全文 / 选择文字 / 填回输入框”。
- 对话里按 Ctrl+F 查找，高亮所有匹配；Alt+↑ / Alt+↓ 在你发的消息之间跳；右侧面板新增“目录”，列出你发过的每一句，并可以把对话复制成 Markdown 或下载 .md。
- Codex 的对话页换成单色、无衬线的样子：灰色气泡、灰色工具时间线、黑色圆形发送按钮，运行中是 Codex 标志轻轻呼吸，不再照搬 Claude 的样子。

- 修复：侧栏项目上的“⋯”菜单点了没反应。
- 修复：macOS 上 Codex 对话页提示“暂时连不上 Codex”“没找到 Codex”（从桌面应用启动时拿不到你终端里的 PATH）。再出问题时，提示里会写明具体原因。
